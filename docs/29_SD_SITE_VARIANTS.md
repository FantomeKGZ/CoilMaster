# Сайты на microSD: мобильная и ПК-версии

## Цель

Дополнительные сайты и справочные материалы на microSD должны открываться в той же версии интерфейса, которая выбрана для основного портала CoilMaster.

## Структура

```text
/web/
  mobile/
  desktop/
  sites/
    reference/
      mobile/
        index.html
      desktop/
        index.html
      common/
        index.html
```

Папка `common` необязательна и используется как резервная версия.

## Правила выбора

- CoilMaster Mobile открывает `/sites/<site>/mobile/`.
- CoilMaster Desktop открывает `/sites/<site>/desktop/`.
- выбранный режим хранится в браузере в `localStorage` под ключом `cm-ui-version`;
- пользователь может вручную переключить версию внутри дополнительного сайта.

## Резервный порядок

Если требуемая версия отсутствует:

1. открыть `common`;
2. предложить другую доступную версию;
3. показать понятное сообщение об отсутствии сайта.

Пустая страница или необработанная ошибка файловой системы недопустимы.

## Безопасность

Дополнительные сайты не получают прямого доступа к SSR. Они могут использовать только разрешённые HTTP API ESP32. Запуск двигателя остаётся возможен только с Arduino клавишей `A` или внешней кнопкой START.

## Первая реализация

Созданы стартовые страницы:

```text
firmware/esp32/web/sites/reference/mobile/index.html
firmware/esp32/web/sites/reference/desktop/index.html
```

Следующий этап — добавить маршрутизацию статических файлов с microSD и ссылки «Справочник» в мобильный и ПК-интерфейсы CoilMaster.
