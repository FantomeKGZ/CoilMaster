Обязательные данные

Для создания карточки нужны только имя и телефон.
Телефон должен содержать не менее 7 цифр.

Дополнительно

Эти данные можно не заполнять и добавить позже в карточке клиента.
Создание клиента не создаёт ремонт и не связывает двигатель. Связь клиента с двигателем фиксируется исторически через ремонт.
