# CoilMaster — подтвержденная распиновка ESP32

Статус: частично подтверждено. В документ включены только подключения, которые были явно согласованы в переписке и тестах.

## Подтвержденные подключения

| GPIO ESP32 | Назначение | Вторая сторона |
|---|---|---|
| GPIO16 | UART2 RX | Принимает данные от Arduino Uno A1 (TX) через LLC |
| GPIO17 | UART2 TX | Передает данные на Arduino Uno A2 (RX) через LLC |
| GPIO21 | I²C SDA | DS3231 |
| GPIO22 | I²C SCL | DS3231 |

## UART2

Рекомендуемая программная конфигурация:

```cpp
constexpr int UART2_RX_PIN = 16;
constexpr int UART2_TX_PIN = 17;

Serial2.begin(57600, SERIAL_8N1, UART2_RX_PIN, UART2_TX_PIN);
```

Начальную скорость 57600 бод выбрали как более надежную для пары ESP32 HardwareSerial ↔ Arduino Uno SoftwareSerial. Скорость 115200 допускается только после отдельного продолжительного теста без ошибок.

## I²C и DS3231

Подтвержденная шина:

- SDA → GPIO21;
- SCL → GPIO22;
- общий GND;
- питание модуля должно соответствовать фактической плате DS3231.

Программная инициализация:

```cpp
Wire.begin(21, 22);
```

## Пока не подтверждено

В предыдущих обсуждениях упоминались следующие функции и модули, но точная распиновка в доступном контексте не зафиксирована:

- Nextion;
- microSD;
- дополнительные кнопки или индикаторы ESP32;
- отдельные линии управления питанием;
- конкретные GPIO для будущих периферийных модулей.

Эти подключения нельзя считать утвержденными до повторной проверки реальной сборки или фотографий.

## Ограничения

- ESP32 использует логику 3,3 В;
- нельзя подавать 5 В непосредственно на GPIO ESP32;
- для связи с Arduino Uno используется преобразователь логических уровней;
- земли ESP32, Arduino Uno и LLC должны быть общими.
