# Итоги списаний ремонта по материалам

На мобильной и настольной страницах списания добавлена локальная сводка истории ремонта по материалам.

Используется существующий запрос:

`GET /api/warehouse/write-offs?repair_id=<ID>`

Интерфейс рассчитывает по полученным подтверждённым движениям три независимых итога:

- медь (`CU`);
- алюминий (`AL`);
- старые движения без материала (`UNKNOWN`).

Для каждой группы показываются:

- количество операций списания;
- суммарная списанная масса.

Общий подтверждённый расход ремонта продолжает браться из серверного поля `total_consumed_g`. Материальная разбивка строится только для отображения и не изменяет журнал склада.

## Правила классификации

- `wire_type=CU` относится к меди;
- `wire_type=AL` относится к алюминию;
- отсутствующий или неизвестный `wire_type` относится к группе «Без материала»;
- неизвестный материал не преобразуется в медь автоматически.

После нового успешного списания одновременно обновляются:

- остаток выбранной бухты;
- общий расход ремонта;
- количество операций по материалам;
- суммарный расход по каждому материалу;
- список подтверждённых движений.
