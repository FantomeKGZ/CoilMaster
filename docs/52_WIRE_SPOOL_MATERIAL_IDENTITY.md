# Материал провода в карточке катушки

## Изменение

Для каждой новой катушки провода теперь обязательно указывается материал проводника:

- `CU` — медь;
- `AL` — алюминий.

API создания катушки:

`POST /api/warehouse/spools`

обязательно принимает поле:

`wire_type`

Допустимые входные значения нормализуются к `CU` или `AL`. Поддерживаются английские и русские варианты названий.

При отсутствии или неизвестном значении API возвращает:

```json
{"error":"wire_type_required_cu_or_al"}
```

с HTTP-кодом `400`.

## Хранение

Новые записи в `/data/warehouse/spools.ndjson` всегда содержат каноническое поле:

```json
{"wire_type":"CU"}
```

или:

```json
{"wire_type":"AL"}
```

## Совместимость

Старые записи без `wire_type` не преобразуются автоматически и не должны неявно считаться медью. Они остаются записями с неизвестным материалом до явного исправления оператором или отдельной миграции.

Это первый этап разделения складских остатков меди и алюминия. Следующий этап — фильтрация рекомендаций калькулятора по целевому материалу и отдельное отображение остатков CU/AL.
