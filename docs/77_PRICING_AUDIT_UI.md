# Страница проверки калькуляции ремонта

Добавлены диагностические страницы:

- `/mobile/pricing-audit.html`;
- `/desktop/pricing-audit.html`.

Страница одновременно читает:

- `GET /api/repairs/costing?repair_id=<ID>`;
- `GET /api/repairs/pricing-history?repair_id=<ID>`.

## Проверяемые инварианты

Интерфейс показывает отдельный результат для каждого условия:

- сумма составляющих совпадает с общей себестоимостью;
- стоимость провода по `CU`, `AL` и `UNKNOWN` совпадает с итогом провода;
- количество списаний по материалам совпадает с общим количеством;
- статус прибыльности подтверждён сервером;
- история получена из append-only журнала;
- активная цена получена из последней редакции;
- количество элементов истории согласовано с метаданными;
- последние значения истории совпадают с активной ценой;
- timestamp последней редакции совпадает;
- история полностью подтверждает текущую цену;
- номер текущей редакции совпадает между двумя API.

## Назначение

Страница предназначена для диагностики данных ремонта после сохранения цены, восстановления SD-карты или проверки работы нескольких вкладок. Она ничего не записывает и не меняет журнал.

## Отображаемые значения

Помимо проверок выводятся текущие:

- себестоимость;
- стоимость работы;
- цена клиенту;
- маржа и убыток;
- статус прибыльности;
- номер редакции;
- время последнего сохранения.
