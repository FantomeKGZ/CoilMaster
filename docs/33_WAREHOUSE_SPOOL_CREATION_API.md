# API создания бухты провода

## Назначение

Первый записывающий API склада создаёт новую активную бухту в файле:

`/data/warehouse/spools.ndjson`

Обязательные данные:

- диаметр провода;
- текущий вес бухты.

Все дополнительные сведения могут быть пустыми и заполняться позже.

## Маршрут

`POST /api/warehouse/spools`

Формат запроса: `application/x-www-form-urlencoded` или `multipart/form-data`.

## Обязательные поля

- `diameter_hundredths_mm` — диаметр в сотых долях миллиметра;
- `current_weight_g` — текущий фактический вес в граммах.

Пример:

- `80` означает `0,80 мм`;
- `13420` означает `13,420 кг`.

## Необязательные поля

- `wire_type` — марка провода;
- `manufacturer` — производитель;
- `supplier` — поставщик;
- `batch` — номер партии;
- `price_per_kg_minor` — цена за килограмм в минимальных денежных единицах;
- `storage_location` — место хранения;
- `comment` — примечание.

## Успешный ответ

HTTP `201 Created`

```json
{
  "created": true,
  "spool_id": 12,
  "diameter_hundredths_mm": 80,
  "current_weight_g": 13420
}
```

## Проверки

- диаметр: от `0,01` до `5,00 мм`;
- вес: от `1 г` до `1000 кг`;
- идентификатор бухты назначается автоматически;
- следующая запись получает `max(spool_id) + 1`;
- строки экранируются перед записью в NDJSON;
- новая бухта всегда создаётся со статусом `ACTIVE`.
