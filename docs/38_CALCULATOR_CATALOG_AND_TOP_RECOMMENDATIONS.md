# Рекомендации калькулятора по всему каталогу проводов

Калькулятор использует не только провода с положительным остатком, но и все диаметры, которые когда-либо были внесены в базу проводов.

## Источники кандидатов

Каждый известный диаметр получает один из статусов:

- `IN_STOCK` — провод сейчас есть на складе;
- `PURCHASE_REQUIRED` — диаметр известен базе, но текущий остаток равен нулю.

Это позволяет одновременно:

1. предложить лучший вариант из фактического остатка;
2. показать более подходящий вариант, который можно докупить;
3. не ограничивать расчёт только случайным текущим набором бухт.

## Количество результатов

WEB-интерфейс получает до трёх рекомендаций.

Порядок сортировки:

1. варианты, имеющиеся на складе;
2. минимальное отклонение суммарного сечения;
3. меньшее количество параллельных жил;
4. варианты, требующие закупки.

Вариант закупки не скрывается, даже когда складской вариант найден. Поэтому мастер сможет сравнить удобный доступный вариант с технически более точным диаметром для закупки.

## Пример

Исходная обмотка:

`3 × 0,80 мм, алюминий`

Возможный результат:

1. `2 × 0,85 мм, медь` — есть на складе;
2. `1 × 1,20 мм, медь` — есть на складе;
3. `2 × 0,83 мм, медь` — требуется закупить.

Каждый результат должен показывать:

- материал;
- диаметр;
- количество параллельных жил;
- отклонение от требуемого сечения;
- остаток на складе;
- статус наличия или закупки.

## Ограничение нагрузки

На ESP32 сохраняются только три лучших варианта. Все остальные комбинации сравниваются последовательно и сразу отбрасываются. Поэтому размер промежуточного списка не растёт вместе с каталогом.

Текущая версия ядра перебирает каждый известный диаметр с количеством одинаковых параллельных жил от 1 до настроенного максимума. Поддержка смешанных комбинаций разных диаметров будет добавлена отдельным этапом после API и проверки текущей модели.
