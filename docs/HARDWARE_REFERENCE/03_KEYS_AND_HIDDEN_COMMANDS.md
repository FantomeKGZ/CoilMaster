# Arduino — клавиши и скрытые команды

Дата: **2026-08-18**  
Проверено по `Core/CM_KeyMapper.cpp` и `firmware/arduino/src/main.cpp`.

## Раскладка клавиатуры 4×4

```text
1  2  3  A
4  5  6  B
7  8  9  C
*  0  #  D
```

## Обычные клавиши

| Клавиша | Действие | Примечание |
|---|---|---|
| `0`…`9` | ввод числа | используется при вводе количества катушек и витков |
| `A` | START / Resume | физический старт или продолжение, только если state machine разрешает |
| `B` | Return Home | сброс текущего пользовательского ввода/сеанса к начальному экрану |
| `C` | Manual Run toggle | включает/выключает ручной режим, если состояние разрешает |
| `D` | Pause | пауза во время разрешённого рабочего состояния |
| `*` | Backspace | удалить последнюю введённую цифру |
| `#` | Confirm | подтвердить введённое значение |

## Внешняя кнопка START

Отдельная физическая кнопка на Arduino D10 полностью дублирует `A`:

```text
START / Resume
```

Она не обходит state machine и не должна запускать двигатель из запрещённого состояния.

## Скрытая аварийная команда: очистка зависшего remote JOB

Последовательность:

```text
D -> * -> # -> D
```

Максимальный интервал между последовательными клавишами — **4 секунды**. Если интервал превышен, последовательность сбрасывается.

### Назначение

Команда используется только для аварийного восстановления синхронизации Arduino ↔ ESP32, когда ESP32 считает, что задание существует или ожидает подтверждения, а нормальная отмена не смогла завершиться.

После безопасной очистки Arduino отправляет ESP32:

```text
CMP1|JOB_CANCEL_ACK|0|CANCELLED|ALL_CLEAR|C|<CRC>
```

### Что команда НЕ делает

`D * # D`:

- не означает `RUN_COMPLETED`;
- не создаёт фиктивное завершение намотки;
- не списывает провод;
- не включает SSR;
- не запускает двигатель;
- не возобновляет работу после reboot;
- не удаляет immutable snapshot/history на ESP32.

### Когда команда блокируется

Аварийная очистка не выполняется в состояниях:

```text
Winding
Paused
ManualRun
CoilComplete
JobComplete
```

Если Arduino действительно содержит remote ESP32 job, безопасная очистка разрешена только если:

```text
state == Ready
currentRunId == 0
completedRuns == 0
```

То есть physical START ещё не происходил и нет физического run evidence.

Если remote job на Arduino уже отсутствует, команда может отправить `ALL_CLEAR`, чтобы ESP32 закрыла зависшее no-run состояние.

## Почему первая клавиша D иногда не ставит Pause

`D` является одновременно началом скрытой последовательности. В production firmware первая `D`, распознанная как начало emergency sequence, перехватывается обработчиком скрытой команды. Если дальше последовательность не продолжена корректно, обработчик сбрасывается.

Поэтому аварийную комбинацию следует вводить намеренно и последовательно.

## Safety-инвариант клавиш

Никакая скрытая команда клавиатуры не должна заменять physical START или создавать ложное доказательство выполнения работы. Любое будущее добавление скрытых комбинаций должно быть документировано в этом файле.
