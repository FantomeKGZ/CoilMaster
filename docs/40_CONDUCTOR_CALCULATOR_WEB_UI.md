# WEB-интерфейс калькулятора проводника

## Страницы

- мобильная: `/mobile/calculator.html`;
- ПК-версия: `/desktop/calculator.html`.

Обе страницы работают с API:

`GET /api/calculator/conductor`

## Ввод

Оператор задаёт:

- исходный материал: алюминий или медь;
- целевой материал;
- диаметр одной исходной жилы;
- количество параллельных исходных жил;
- допустимое отклонение;
- максимальное количество целевых жил.

Расширенные коэффициенты Al → Cu и Cu → Al пока доступны для проверки методики. После утверждения они будут перенесены в постоянные настройки.

## Результат

Интерфейс показывает до трёх вариантов:

- количество параллельных жил;
- диаметр каждой жилы;
- отклонение от требуемого сечения;
- остаток на складе;
- статус `есть на складе` или `требуется закупить`.

## Навигация

Калькулятор добавлен в основное меню обеих версий CoilMaster:

- мобильное меню: `Расчёт`;
- боковое меню ПК: `Калькулятор`.

## Ограничение текущей версии

Результат пока использует одинаковый диаметр всех параллельных целевых жил. Смешанные комбинации разных диаметров будут реализованы после практической проверки базового двустороннего пересчёта.
