# Стоимость списаний провода в истории ремонта

Мобильная и настольная страницы списания провода показывают не только массу, но и денежную стоимость подтверждённых операций.

Используется ответ:

```text
GET /api/warehouse/write-offs?repair_id=<ID>
```

## Что отображается

- общая подтверждённая масса списанного провода;
- общая стоимость списанного провода;
- масса, количество операций и стоимость отдельно для `CU`, `AL` и `UNKNOWN`;
- стоимость каждой операции;
- цена за килограмм, сохранённая в движении на момент списания;
- материал, диаметр, бухта, изменение веса, дата и комментарий.

После успешного нового списания интерфейс сразу показывает стоимость операции из поля `consumed_value_minor`, затем повторно загружает серверную историю и итоговые значения.

## Проверка серверных итогов

Серверные итоги используются как основной источник только когда одновременно выполняются проверки:

```text
material_totals_source = SERVER
material_totals_match_total = true
material_count_match_count = true
material_values_match_total = true
```

При несогласованности интерфейс явно сообщает о проблеме и строит резервную разбивку по массиву `items`.

## Округление

Стоимость операции рассчитывается сервером до ближайшей минимальной денежной единицы:

```text
(mass_g × price_per_kg_minor + 500) / 1000
```

Интерфейс не пересчитывает стоимость по массе и цене, если сервер уже вернул `consumed_value_minor`.
