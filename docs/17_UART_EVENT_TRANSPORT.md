# CoilMaster — UART события Arduino Uno → ESP32

## Подключение

```text
Arduino A1 (TX) -> LLC -> ESP32 GPIO16 (RX2)
Arduino A2 (RX) <- LLC <- ESP32 GPIO17 (TX2)
GND Arduino     -------- GND ESP32
```

Стороны логического преобразователя:

- Arduino Uno: HV = 5 V;
- ESP32: LV = 3.3 V;
- земля общая.

## Параметры линии

- скорость: `9600 baud`;
- формат: `8N1`;
- Arduino использует `SoftwareSerial` на A2/A1;
- USB Serial `115200` остаётся только для диагностики.

## Формат кадра событий

Кадр представляет собой одну ASCII-строку:

```text
CMP1|EVT|EVENT_NAME|SESSION_ID|RUN_ID|COMPLETED_RUNS|CRC16\n
```

Примеры:

```text
CMP1|EVT|RUN_STARTED|1|1|0|XXXX
CMP1|EVT|RUN_COMPLETED|1|1|1|XXXX
```

`CRC16` рассчитывается по части строки до последнего разделителя перед CRC алгоритмом CRC-16/CCITT-FALSE:

- начальное значение `0xFFFF`;
- полином `0x1021`;
- без отражения;
- без финального XOR.

## Назначение полей

- `CMP1` — версия текстового транспортного формата;
- `EVT` — тип сообщения: событие;
- `EVENT_NAME` — `RUN_STARTED` или `RUN_COMPLETED`;
- `SESSION_ID` — идентификатор активного сеанса;
- `RUN_ID` — уникальный идентификатор фактического прохода;
- `COMPLETED_RUNS` — число полностью завершённых проходов в текущем сеансе;
- `CRC16` — четыре шестнадцатеричных символа.

## Текущее ограничение

На этом этапе реализована односторонняя передача событий Arduino → ESP32. Подтверждения `ACK`, повторная отправка неподтверждённых событий и приём заданий от ESP32 будут добавлены следующим этапом поверх этого транспорта.

ESP32 не получает права напрямую управлять SSR. Любой старт подтверждается локально клавишей `A` или внешней кнопкой START.
