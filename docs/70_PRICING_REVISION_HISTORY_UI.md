# История редакций цены в интерфейсе

Мобильная и настольная страницы калькуляции ремонта используют:

`GET /api/repairs/pricing-history?repair_id=<ID>`

## Отображение

Для каждой редакции показываются:

- последовательный номер `revision`;
- дата и время сохранения;
- стоимость работы;
- цена клиенту;
- валюта.

Последняя запись журнала помечается как `текущая`.

Мобильная версия выводит редакции карточками. Настольная версия выводит их таблицей.

## Проверка ответа

Интерфейс считает историю согласованной только когда одновременно выполняются условия:

- `source` равен `APPEND_ONLY_LOG`;
- `count` совпадает с количеством элементов `items`;
- `latest_revision` совпадает с номером последней записи;
- для пустой истории `latest_revision` равен нулю.

При расхождении показывается явное предупреждение, но сами записи остаются видимыми для диагностики.

## Обновление

После успешного сохранения калькуляции страница повторно загружает:

- текущую калькуляцию;
- метаданные последней редакции;
- полную историю цены.

Предыдущие редакции не удаляются и не редактируются интерфейсом.
