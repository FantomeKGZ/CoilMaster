# CoilMaster — Arduino Core

## Назначение

Arduino Uno является реальным контроллером станка. Она должна продолжать базовую намотку даже при отсутствии ESP32.

## Ответственность

- опрос клавиатуры 4×4;
- внешняя кнопка START на D10;
- LCD1602 I²C;
- датчик Холла SS49E на A0;
- SSR-40DA на D12;
- активный зуммер на D11;
- машина состояний намотки;
- прием и передача заданий через CMP;
- подтверждение фактически выполненных катушек.

## Основные модули

```text
ArduinoApp
├── InputManager
├── StateMachine
├── WindingController
├── HallCounter
├── LcdView
├── OutputController
├── CmpLink
└── Diagnostics
```

## Машина состояний

```text
ENTER_COIL_COUNT
ENTER_COIL_TURNS
READY
WINDING
PAUSED
COIL_DONE
JOB_DONE
MANUAL
ERROR
```

Клавиша `B` возвращает в начальное меню без перезагрузки платы и очищает только текущий пользовательский сеанс.

## Управление

| Ввод | Действие |
|---|---|
| A | старт или продолжение |
| B | отмена текущего сеанса и возврат домой |
| C | ручной ход без счета, повторное нажатие — остановка |
| D | пауза |
| * | удалить последнюю цифру |
| # | подтвердить ввод |
| D10 | полный дубль клавиши A |

## Ограничения Arduino Uno

- без `String`;
- без `new`, `malloc` и динамических контейнеров;
- без блокирующих ожиданий и длинных `delay()`;
- фиксированные массивы;
- строки интерфейса по возможности во Flash;
- безопасное состояние SSR — `LOW` при запуске, сбросе и ошибке.

## Модель задания

Одно задание относится только к одному типу обмотки: рабочей или пусковой.

```text
WindingJob
├── jobId
├── source
├── windingType
├── coilCount
├── turns[coilCount]
├── currentCoil
├── currentTurns
└── status
```

Полная база двигателей не хранится в RAM Arduino. Arduino получает только текущее задание.

## События для ESP32

Arduino передает:

- задание, введенное с клавиатуры;
- принятие или отклонение задания с Web;
- начало задания;
- паузу и продолжение;
- завершение каждой катушки;
- завершение всей намотки;
- отмену или ошибку;
- телеметрию Hall, SSR и текущего состояния.
