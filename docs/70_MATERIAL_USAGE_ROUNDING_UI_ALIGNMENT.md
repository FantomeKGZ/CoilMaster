# Согласование округления стоимости материалов в интерфейсе

Стоимость подтверждённого списания дополнительного материала рассчитывается на ESP32 по формуле:

```text
(quantity_milli × price_per_unit_minor + 500) / 1000
```

Поле ответа API:

```json
{
  "line_cost_source": "PERSISTED_USAGE_SNAPSHOT",
  "value_rounding": "NEAREST_MINOR_UNIT"
}
```

Мобильная и настольная страницы `materials.html` теперь проверяют именно `NEAREST_MINOR_UNIT`.

Ранее интерфейс ожидал устаревшее значение `TRUNCATE_MINOR_UNIT`. Из-за этого корректно выполненное списание показывалось как неподтверждённое, хотя сервер уже использовал округление до ближайшей минимальной денежной единицы.

Исправление не меняет формат данных и не создаёт новые записи. Оно только синхронизирует проверку клиентского интерфейса с действующим серверным контрактом.

Изменённые файлы:

- `firmware/esp32/web/mobile/materials.html`;
- `firmware/esp32/web/desktop/materials.html`.
