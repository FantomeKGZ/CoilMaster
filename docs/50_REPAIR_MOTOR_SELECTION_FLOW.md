# Выбор двигателя при создании ремонта

## Назначение

Переход из каталога двигателей в создание ремонта должен сохранять выбранную карточку двигателя.

Поддерживаются два источника выбора:

1. параметр URL `motor_id`;
2. последнее значение `cm-selected-motor` в `localStorage`.

Параметр URL имеет приоритет.

## Маршруты

Мобильный интерфейс:

`/mobile/repairs.html?motor_id=12`

Интерфейс ПК:

`/desktop/repairs.html?motor_id=12`

После загрузки каталога система проверяет, что указанный `motor_id` существует, и только затем выбирает его в форме.

## Сохранение выбора

Выбор обновляется при:

- ручной смене двигателя в списке;
- переходе из каталога;
- быстром создании двигателя;
- успешном создании ремонта.

Если оператор очищает список, сохранённый выбор удаляется.

## Отображение

В подписи двигателя используются:

- название;
- модель;
- производитель;
- программа витков.

Это позволяет различать похожие карточки с одинаковыми программами витков.
