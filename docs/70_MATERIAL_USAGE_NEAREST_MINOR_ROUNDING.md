# Округление стоимости дополнительных материалов

Для новых подтверждённых списаний дополнительных материалов стоимость строки рассчитывается по формуле:

```text
(quantity_milli × price_per_unit_minor + 500) / 1000
```

Расчёт выполняется через `uint64_t` и округляет результат до ближайшей минимальной денежной единицы.

## Причина изменения

Ранее применялось целочисленное деление без прибавления `500`, поэтому дробная часть всегда отбрасывалась вниз. Это могло систематически занижать стоимость отдельных операций.

Теперь для новых записей используется та же политика, что и для списаний провода:

```json
{
  "value_rounding": "NEAREST_MINOR_UNIT"
}
```

## Совместимость с историей

Старые записи не пересчитываются. Калькуляция ремонта продолжает использовать сохранённое поле `line_cost_minor` из каждой операции.

Поэтому:

- уже закрытые ремонты не меняют себестоимость;
- новая цена материала не влияет на прошлые списания;
- новое правило применяется только к операциям, созданным после обновления прошивки;
- источник стоимости остаётся `PERSISTED_USAGE_SNAPSHOT`.
