# Отложенная реализация: неразобранные намотки и аналоги двигателей

Этот документ сохраняет согласованную логику для последующей реализации.

## Неразобранные намотки

Программа, введённая на клавиатуре Arduino, после запуска и завершения должна передаваться на ESP32 полным снимком:

- источник `ARDUINO_KEYPAD`;
- тип обмотки;
- количество катушек;
- последовательность витков;
- идентификаторы запуска и сессии;
- время начала и завершения;
- провод, если он известен.

ESP32 создаёт или обновляет карточку со статусом `UNASSIGNED`. Одинаковые программы группируются, но каждый фактический запуск сохраняется отдельно.

Отдельные страницы:

- `/mobile/unassigned-windings.html`;
- `/desktop/unassigned-windings.html`.

На странице нужны чекбоксы и групповые действия:

- создать один двигатель из нескольких выбранных обмоток;
- добавить к существующему двигателю;
- привязать к одному ремонту;
- создать или выбрать группу аналогов;
- пометить обработанными;
- удалить из неразобранных без физического уничтожения истории.

## Сравнение обмоток

Совпадение только витков не является дублем двигателя.

Используются два уровня ключей:

1. `turns_key` — тип обмотки, количество катушек и последовательность витков;
2. `specification_key` — витки плюс материал, диаметры, количество параллельных жил и другие параметры провода.

Разные провода при одинаковых витках сохраняются как разные варианты обмотки.

## Двигатели и клоны

Каждый двигатель остаётся отдельной карточкой и может иметь:

- название;
- модель;
- производителя;
- теги;
- принадлежность к группе аналогов.

Название, модель и теги используются для различения и поиска, но не для технического определения одинаковой обмотки.

Один вариант обмотки может быть связан с несколькими двигателями-клонами.

## Счётчики

Нужно хранить:

- счётчик намоток конкретного двигателя;
- общий счётчик общего варианта обмотки или группы аналогов.

Если несколько двигателей используют одну полную спецификацию обмотки, для них отображается один общий счётчик совпадающего варианта. После привязки фактического запуска к конкретной модели дополнительно увеличивается её собственный счётчик.

Автоматическое объединение запрещено. Система показывает совпадения и предлагает варианты, окончательное решение принимает оператор.
