# История списания дополнительных материалов

## Маршрут

`GET /api/materials/usage`

Маршрут использует тот же адрес, что и подтверждение списания:

- `GET` — чтение истории;
- `POST` — новое подтверждённое списание.

## Фильтры

История конкретного ремонта:

`GET /api/materials/usage?repair_id=42`

История конкретного материала:

`GET /api/materials/usage?material_id=3`

Материал в конкретном ремонте:

`GET /api/materials/usage?repair_id=42&material_id=3`

Ограничение числа строк:

`GET /api/materials/usage?repair_id=42&limit=50`

Допустимый `limit`: от 1 до 100. Значение по умолчанию — 50.

## Назначение

API позволяет показывать в калькуляции не только общую стоимость материалов, но и полный состав ремонта:

- какой материал был списан;
- в каком количестве;
- по какой цене на момент ремонта;
- какова стоимость отдельной позиции;
- когда и с каким комментарием выполнено списание.

Изменение текущей цены материала не меняет цену старых операций.
