# Проверки целостности стоимости списания материалов

Успешный ответ `POST /api/materials/usage` дополнительно содержит серверные проверки стоимости и валюты:

```json
{
  "line_cost_matches_formula": true,
  "currency_matches_policy": true,
  "currency_policy": "KGS_ONLY"
}
```

## Проверка стоимости

ESP32 повторно рассчитывает ожидаемую стоимость после завершения подтверждённого списания:

```text
ROUND(quantity_milli * unit_price_minor / 1000)
```

Расчёт выполняется через 64-битное промежуточное произведение и округление до ближайшей минимальной денежной единицы.

`line_cost_matches_formula` имеет значение `true`, когда сохранённый `line_cost_minor` совпадает с результатом формулы.

## Проверка валюты

Для дополнительных материалов действует политика `KGS_ONLY`.

`currency_matches_policy` подтверждает, что валюта результата списания равна `KGS`.

## Историческая стоимость

Проверка не меняет правило исторических данных:

- цена фиксируется в момент списания;
- в журнал сохраняется `line_cost_minor`;
- последующее изменение складской цены не пересчитывает старый ремонт;
- калькуляция использует сохранённый снимок операции.
