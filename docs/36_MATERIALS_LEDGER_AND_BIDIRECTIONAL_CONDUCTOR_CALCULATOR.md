# CoilMaster — материалы, калькуляция ремонта и двусторонний пересчёт Al ↔ Cu

Дата: 2026-08-05

## 1. Раздел «Калькуляция ремонта»

Раздел работает подобно кассе, но учитывает фактический расход материалов по каждому ремонту:

`ремонт → использованные материалы → количество → цена → итоговая себестоимость`

В итог входят:

- провод по конкретным бухтам;
- лак;
- подшипники;
- пазовые клинья и палочки;
- межфазная бумага;
- изоляция;
- выводной провод;
- кембрик;
- клеммы;
- любые другие материалы;
- выполненные работы;
- дополнительные расходы и скидки.

## 2. Универсальный справочник материалов

Для каждого материала задаются:

- `material_id`;
- название;
- категория;
- единица измерения;
- текущий остаток;
- цена за единицу;
- минимальный остаток;
- поставщик;
- место хранения;
- комментарий;
- активность.

Допустимые единицы:

- штуки;
- граммы;
- килограммы;
- миллилитры;
- литры;
- метры;
- квадратные метры;
- упаковки;
- комплекты.

Материал можно добавить прямо из карточки ремонта. Цена фиксируется в движении на момент списания, поэтому изменение текущей цены не меняет старую себестоимость.

## 3. Движения материалов

Типы операций:

- `RECEIPT` — приход;
- `WRITE_OFF` — списание на ремонт;
- `ADJUSTMENT` — инвентаризационная корректировка;
- `RETURN` — возврат;
- `DISPOSAL` — брак или утилизация.

Каждая операция содержит `movement_id`, `material_id`, `repair_id`, количество, единицу, цену, итоговую стоимость, дату, комментарий и статус подтверждения.

Провод остаётся отдельным складским объектом: конкретная бухта, диаметр, вес до, вес после, фактический расход и цена за килограмм на момент ремонта. В калькуляции он объединяется с другими материалами только по стоимости.

## 4. Двусторонний калькулятор проводников

Название раздела: **«Пересчёт Al ↔ Cu»**.

Калькулятор должен работать в обоих направлениях:

- алюминий → медь;
- медь → алюминий.

Направление выбирает оператор. Архитектура не должна быть привязана только к одному виду исходного материала.

## 5. Входные данные

Минимально:

- исходный материал: `AL` или `CU`;
- целевой материал: `CU` или `AL`;
- количество параллельных исходных жил;
- диаметр каждой исходной жилы;
- число витков;
- количество катушек;
- тип обмотки: рабочая или пусковая;
- допустимое место в пазу или коэффициент заполнения.

Дополнительно:

- мощность;
- напряжение;
- ток;
- схема соединения;
- число пазов;
- число полюсов;
- длина активной части;
- средняя длина витка;
- температурный класс;
- охлаждение.

## 6. Расчётная модель

Полное исходное сечение:

```text
S_source = N_source × π × d_source² / 4
```

Требуемое целевое сечение:

```text
S_target = S_source × K_source_to_target
```

Используются два независимых настраиваемых коэффициента:

- `K_AL_TO_CU`;
- `K_CU_TO_AL`.

Они хранятся в настройках, а не зашиваются одной постоянной. Это позволит учитывать методику мастерской, температурный режим, марку провода, допустимый нагрев и практический опыт.

Для каждого выбранного диаметра:

```text
S_wire = π × d_target² / 4
S_total = N_target × S_wire
```

Программа показывает отклонение `S_total` от требуемого `S_target`.

## 7. Подбор по складу

Калькулятор получает остатки склада и ранжирует варианты:

1. полностью подходящий провод есть в достаточном количестве;
2. подходящее сочетание нескольких параллельных жил есть на складе;
3. сечение подходит, но остатка недостаточно;
4. подходящего диаметра нет — сформировать рекомендацию к покупке.

Для каждого варианта показываются:

- материал;
- количество параллельных жил;
- диаметр;
- суммарное сечение;
- отклонение в процентах;
- ориентировочная масса;
- наличие на складе;
- дефицит;
- ориентировочная стоимость.

## 8. Безопасность расчёта

Калькулятор является помощником мастера, а не автоматическим разрешением на перемотку.

Он должен предупреждать, если:

- отклонение сечения превышает заданный предел;
- целевой провод не помещается в паз;
- недостаточно исходных данных;
- складского остатка не хватает;
- выбранный вариант требует проверки тока, нагрева или коэффициента заполнения.

Окончательный вариант подтверждает мастер.

## 9. Порядок реализации

1. Универсальный справочник дополнительных материалов.
2. Приход, списание и корректировка остатков.
3. Калькуляция ремонта с проводом, материалами и работой.
4. Базовое ядро двустороннего пересчёта `AL ↔ CU`.
5. Подбор одиночного и многожильного варианта.
6. Проверка наличия и дефицита по складу.
7. Сохранение расчёта в карточку ремонта.
