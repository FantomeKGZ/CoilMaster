# Классификация старых бухт в интерфейсе

Мобильная и настольная страницы склада теперь позволяют назначить материал активным старым бухтам, у которых отсутствует `wire_type`.

## Доступные действия

Для записи `UNKNOWN` показываются две кнопки:

- `Назначить медь` / `Медь` — отправляет `wire_type=CU`;
- `Назначить алюминий` / `Алюминий` — отправляет `wire_type=AL`.

Запрос:

`POST /api/warehouse/spools/material`

Поля формы:

- `spool_id`;
- `wire_type`.

## Защита от случайного назначения

Перед отправкой интерфейс показывает подтверждение с номером бухты и выбранным материалом.

Во время запроса обе кнопки этой бухты блокируются, чтобы исключить повторную отправку.

После успешного назначения интерфейс повторно загружает:

- раздельную сводку склада;
- текущий список бухт.

Назначенная бухта исчезает из раздела `UNKNOWN` и появляется в `CU` или `AL`.

## Ограничения

- кнопки показываются только для `material_class=UNKNOWN`;
- уже классифицированные бухты не имеют действия изменения материала;
- ошибка API не меняет локальное состояние, кнопки снова становятся доступными;
- назначение остаётся одноразовым согласно ограничениям backend.
