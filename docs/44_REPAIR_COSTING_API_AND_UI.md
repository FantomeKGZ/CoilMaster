# Калькуляция ремонта

## Назначение

Раздел объединяет стоимость подтверждённо списанного провода, дополнительных материалов, работы мастера и конечную цену для клиента.

## Источники

- провод: `/data/warehouse/movements.ndjson`, только `WRITE_OFF` со статусом `CONFIRMED`;
- дополнительные материалы: `/data/materials/usage.ndjson`;
- работа и цена клиенту: `/data/repairs/pricing.ndjson`.

Все записи связываются через `repair_id`.

## API

### Получить калькуляцию

`GET /api/repairs/costing?repair_id=42`

Возвращаются:

- стоимость провода;
- стоимость дополнительных материалов;
- стоимость работы;
- общая себестоимость;
- цена клиенту;
- маржа;
- количество строк списания провода и материалов.

### Сохранить работу и цену клиенту

`POST /api/repairs/costing`

Поля:

- `repair_id`;
- `labour_cost_minor`;
- `client_price_minor`;
- `currency`;
- `timestamp`.

Новая запись дополняет историю. При чтении используется последняя запись для данного ремонта.

## WEB

- `/mobile/costing.html`;
- `/desktop/costing.html`.

Страница позволяет загрузить калькуляцию по номеру ремонта, увидеть себестоимость и сохранить стоимость работы и итоговую цену клиенту.

## Ограничение текущего этапа

Карточки ремонтов ещё не реализованы, поэтому `repair_id` пока вводится вручную. После появления раздела ремонтов страница будет открываться непосредственно из карточки ремонта.
