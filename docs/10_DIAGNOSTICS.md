# CoilMaster — диагностика и калибровка

## Назначение

Диагностика доступна локально на Arduino и через Web-интерфейс ESP32. Опасные тесты не выполняются без физического подтверждения возле станка.

## Калибровка Hall SS49E

Web-страница отображает:

- текущее `analogRead(A0)`;
- минимальное и максимальное значение за период;
- текущий порог;
- гистерезис;
- число обнаруженных импульсов;
- состояние магнита: обнаружен/не обнаружен.

Новый порог передается Arduino, проверяется по допустимому диапазону и сохраняется только после явного подтверждения.

## Проверки узлов

### Клавиатура

Показывает последнюю нажатую клавишу и карту обнаруженных кнопок.

### LCD1602

Вывод тестовых строк, заполнение символами и проверка подсветки без нарушения активной намотки.

### Hall

Живое значение, порог, гистерезис и тестовый счет импульсов.

### Зуммер

Короткий ограниченный сигнал. Блокирующие длинные последовательности запрещены.

### UART

- состояние соединения;
- число принятых и переданных пакетов;
- CRC-ошибки;
- тайм-ауты;
- последнее время обмена;
- версии протокола обеих сторон.

### RTC DS3231

Время, дата, статус модуля и признак потери питания.

### microSD

Наличие карты, объем, свободное место, возможность чтения/записи и результат проверки файловой системы.

### SSR

SSR-тест разрешается только если:

1. Arduino не выполняет намотку;
2. ручной режим выключен;
3. Web запросил подготовку теста;
4. оператор подтвердил тест физически возле станка;
5. тест имеет жесткое ограничение времени;
6. любое нарушение связи немедленно переводит SSR в `LOW`.

## Журнал диагностики

ESP32 сохраняет дату, тип теста, результат, длительность и коды ошибок. Журнал не должен содержать персональные данные без необходимости.
