# CoilMaster OS

**CoilMaster OS** — модульная программная платформа для управления станком намотки электрических двигателей.

---

# Проект

**Название:** CoilMaster OS

**Версия:** Release 0.1.0

**Build:** 002A

**Package:** 01.1 Foundation

**Статус:** Development

---

# Архитектура

Система состоит из двух независимых контроллеров.

## Arduino UNO

Отвечает за работу оборудования в режиме реального времени.

Функции:

- Подсчёт витков
- Работа с датчиком Холла
- Управление LCD1602
- Работа с клавиатурой
- Управление SSR
- Управление звуковым сигналом
- Выполнение команд намотки
- Обмен данными с ESP32

---

## ESP32

Отвечает за сервисные функции.

Функции:

- Wi-Fi
- Web Server
- FTP
- Работа с microSD
- RTC DS3231
- База двигателей
- Справочник
- Логирование
- Резервное копирование
- OTA (планируется)

# Протокол

Взаимодействие Arduino и ESP32 осуществляется только через протокол **CMP (CoilMaster Protocol)**.

---

# Основные принципы

- Модульная архитектура
- Разделение ответственности устройств
- Отсутствие прямого доступа к оборудованию из прикладных модулей
- Единый стиль кода
- Документация обновляется одновременно с кодом
