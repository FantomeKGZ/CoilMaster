# Проверка похожих двигателей в интерфейсе

Мобильная и настольная страницы каталога двигателей выполняют проверку через:

`GET /api/motors/similar`

перед отправкой новой карточки в `POST /api/motors`.

## Поведение

Если совпадений по программе витков нет, карточка сохраняется сразу.

Если найдены карточки с такой же программой, интерфейс показывает:

- количество записей с той же программой;
- количество совпадений по названию, модели или производителю;
- список похожих карточек и уровень совпадения.

Оператор может после просмотра нажать:

`Всё равно создать отдельный двигатель`

Проверка не блокирует создание и не объединяет записи автоматически.

## Поля карточки

Формы поддерживают:

- название;
- модель;
- производителя;
- программу витков;
- теги;
- комментарий.

## Поиск каталога

Поле поиска использует `GET /api/motors?q=...` и ищет по названию, модели, производителю, тегам и программе витков.

## Безопасность отображения

Значения, полученные из API, экранируются перед вставкой в HTML, чтобы пользовательский текст в названии, модели и тегах не интерпретировался как разметка.
