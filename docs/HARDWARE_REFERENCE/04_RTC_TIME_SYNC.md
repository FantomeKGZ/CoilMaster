# DS3231 — установка времени и автоматическая синхронизация Бишкек

Дата: **2026-08-18**  
Source of truth: `cmp-protocol-v1`

## Подключение

DS3231 подключён к ESP32 по I²C:

```text
DS3231 SDA -> ESP32 GPIO21
DS3231 SCL -> ESP32 GPIO22
GND        -> GND
VCC        -> питание модуля согласно фактической плате DS3231
```

I²C-адрес DS3231: `0x68`.

## Как хранится время

DS3231 хранит локальное время CoilMaster. Для установки по интернету используется время Кыргызстана / Бишкек:

```text
Часовой пояс: Asia/Bishkek
UTC offset:   +06:00
DST:          нет
```

В ESP32 для SNTP используется фиксированное смещение UTC+6, соответствующее Бишкеку.

## Автоматическая синхронизация через интернет

После подключения ESP32 к сохранённой Wi-Fi STA-сети `NetworkManager` автоматически передаёт состояние подключения модулю RTC.

NTP-серверы:

```text
pool.ntp.org
time.google.com
time.cloudflare.com
```

Последовательность:

1. ESP32 подключается к интернету через сохранённый Wi-Fi профиль.
2. SNTP получает сетевое время.
3. Время переводится в UTC+6.
4. CoilMaster проверяет, что runtime находится в безопасном idle-состоянии.
5. Только после этого время записывается в DS3231.
6. Значение перечитывается из DS3231 и проверяется.

При отсутствии интернета DS3231 продолжает работать автономно от своей батареи.

Если интернет появился позже, синхронизация выполняется автоматически. При временной ошибке выполняется повторная попытка примерно через 30 секунд. После успешной синхронизации предусмотрено периодическое обновление примерно раз в 6 часов.

## Safety

Автоматическая синхронизация времени:

- не запускает намотку;
- не включает SSR;
- не создаёт `RUN_STARTED` или `RUN_COMPLETED`;
- не меняет winding job state;
- не выполняет списание провода;
- откладывает запись RTC, если CoilMaster не может доказать безопасный idle.

## Ручная установка времени

Web использует:

```text
POST /api/system/time
```

с полями:

```text
year
month
day
hour
minute
second
confirmed=true
```

Ручная установка также разрешена только при безопасном idle-состоянии.

Web-кнопка «Установить время с этого устройства» отправляет локальное время телефона/компьютера. Поэтому устройство, с которого открыта страница, само должно иметь правильные дату, время и часовой пояс.

## Что исправлено в драйвере DS3231

Предыдущая реализация имела лишнюю точку отказа: после каждой установки времени она безусловно перезаписывала status register DS3231, даже если флаг Oscillator Stop Flag (`OSF`) уже был сброшен.

Теперь:

- status register записывается только если `OSF` действительно установлен;
- операция I²C имеет короткую повторную попытку;
- после записи выполняется обратное чтение;
- допускается абсолютное расхождение не более 2 секунд при проверке;
- в Serial выводится точная причина ошибки вместо одного общего сообщения.

Возможные причины ручной ошибки в Serial:

```text
RTC set failed: NOT_INITIALIZED
RTC set failed: INVALID_DATETIME
RTC set failed: TIME_REGISTER_WRITE_FAILED
RTC set failed: STATUS_READ_FAILED
RTC set failed: OSF_CLEAR_FAILED
RTC set failed: VERIFY_READ_FAILED
RTC set failed: VERIFY_TIME_MISMATCH
```

Успешная автоматическая синхронизация выводит:

```text
RTC NTP sync OK: Asia/Bishkek YYYY-MM-DD HH:MM:SS
```

## Проверка после прошивки

1. Прошить ESP32 текущей версией `cmp-protocol-v1`.
2. Оставить станок без активной намотки/неопределённого задания.
3. Подключить ESP32 к Wi-Fi с доступом в интернет.
4. Открыть Serial Monitor на `115200`.
5. Дождаться сообщения `RTC NTP sync OK: Asia/Bishkek ...`.
6. Открыть настройки CoilMaster и проверить отображаемое время DS3231.
7. Отключить питание ESP32 на несколько минут, оставив батарею DS3231 установленной.
8. После включения убедиться, что часы сохранили правильное время.

Если вместо успешной синхронизации появляется `RTC set failed: ...`, этот код является основной диагностикой для дальнейшей проверки I²C, питания или самого модуля DS3231.
