# Общая цена провода за 1 кг

## Решение

Цена больше не вводится отдельно для каждой бухты.

В складе задаётся одна общая цена провода за один килограмм. Все активные бухты используют это значение при расчёте стоимости остатка и фактического расхода.

## Хранение

История изменений цены хранится отдельно от бухт:

`/data/warehouse/price.ndjson`

Каждая новая установка цены добавляет запись. Текущей считается последняя корректная запись.

Пример:

```json
{"price_per_kg_minor":125000,"currency":"KGS"}
```

`price_per_kg_minor` хранится в минимальных денежных единицах. Для кыргызского сома значение `125000` означает `1250,00 сом/кг`.

## API

### Получить текущую цену

`GET /api/warehouse/price`

Ответ:

```json
{
  "configured": true,
  "price_per_kg_minor": 125000,
  "currency": "KGS"
}
```

### Установить общую цену

`POST /api/warehouse/price`

Поля:

- `price_per_kg_minor` — обязательное;
- `currency` — необязательное, по умолчанию `KGS`.

## Создание бухты

При создании бухты цена больше не передаётся. Оператор вводит только:

- диаметр;
- текущий вес;
- необязательные сведения о партии, производителе и месте хранения.

## Расчёты

Стоимость остатка:

`остаток в кг × общая цена за кг`

Стоимость фактического расхода после взвешивания:

`фактический расход в кг × общая цена за кг`

После изменения общей цены новые расчёты выполняются по новому значению. Для истории ремонта позднее будет сохраняться снимок цены, действовавшей в момент подтверждённого списания, чтобы старая себестоимость не менялась задним числом.
