# Проверки целостности списания дополнительных материалов в интерфейсе

Мобильная и настольная страницы `materials.html` усилены проверками до и после отправки списания.

## Проверки до запроса

Интерфейс не отправляет списание, если:

- ремонт не выбран;
- материал не выбран;
- количество не является положительным числом;
- запрошенное количество превышает текущий остаток из каталога ESP32.

Перед списанием оператор видит текущий остаток и цену выбранного материала.

## Обработка ответа ESP32

При ответе `404 repair_not_found` интерфейс сообщает, что выбранный ремонт отсутствует и списание не выполнено.

Успешный ответ считается подтверждённым только при наличии:

```json
{
  "repair_reference_validated": true
}
```

После подтверждения интерфейс показывает:

- стоимость операции из `line_cost_minor`;
- новый остаток из `remaining_quantity_milli`;
- подтверждение связи расхода с ремонтом на стороне ESP32.

Если сервер не возвращает признак проверки связи, выводится предупреждение вместо обычного сообщения об успехе.

## Защита от повторной отправки

Кнопка списания блокируется на время запроса и снова включается после завершения операции. После успешной записи каталог материалов загружается заново, поэтому следующий расход проверяется уже по обновлённому остатку.
