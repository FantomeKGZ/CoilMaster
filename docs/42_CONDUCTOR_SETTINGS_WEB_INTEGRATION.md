# Интеграция настроек калькулятора в WEB

## Что изменено

Параметры конвертации проводника вынесены из формы расчёта в раздел `Настройки` обеих версий интерфейса.

Страницы:

- `/mobile/settings.html`;
- `/desktop/settings.html`.

Настраиваются:

- коэффициент алюминий → медь;
- коэффициент медь → алюминий;
- допустимое отклонение;
- максимальное число целевых параллельных жил;
- разрешение смешанных диаметров.

## Работа калькулятора

Страницы:

- `/mobile/calculator.html`;
- `/desktop/calculator.html`.

Перед расчётом они автоматически загружают параметры из:

`GET /api/calculator/settings`

Пользователь вводит только данные исходной обмотки:

- материал;
- диаметр одной жилы;
- количество параллельных жил;
- направление конвертации.

Коэффициенты не требуется вводить при каждом расчёте.

## Сохранение

Формы настроек отправляют:

`POST /api/calculator/settings`

После сохранения новые параметры применяются ко всем последующим расчётам мобильной и ПК-версии.

## Результаты

Интерфейс умеет показывать обычные и смешанные варианты, полученные из API:

- `2 × 0,85 мм`;
- `1 × 0,80 мм + 1 × 0,71 мм`.

Для каждого результата отображаются:

- место в рейтинге;
- состав проводников;
- отклонение;
- наличие на складе или необходимость закупки.
