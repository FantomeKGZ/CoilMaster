# Поля идентификации двигателя

## Назначение

Одинаковая программа витков не считается доказательством того, что записи относятся к одному двигателю.

Для различения похожих и клонированных двигателей карточка двигателя теперь хранит:

- `name` — название;
- `model` — модель;
- `manufacturer` — производитель;
- `tags` — пользовательские теги;
- `coil_program` — программа витков;
- `comment` — комментарий.

Обязательными остаются только `name` и `coil_program`.

## Хранение

Карточки сохраняются в:

`/data/workshop/motors.ndjson`

Пример:

```json
{"motor_id":12,"name":"Leo","model":"XKm 80-1","manufacturer":"Leo Group","tags":"насос,2.2 кВт,24 паза","coil_program":"140/100/80/40","status":"ACTIVE"}
```

## API

Создание:

`POST /api/motors`

Поиск:

`GET /api/motors?q=...`

Для обратной совместимости также поддерживается:

`GET /api/motors?name=...`

Поиск выполняется одновременно по названию, модели, производителю, тегам и программе витков.

## Правило дублей

Совпадение программы витков не блокирует создание новой карточки двигателя.
Название, модель, производитель и теги позволяют отличить двигатели разных производителей, даже если программа витков совпадает.

Группы аналогов и общие счётчики будут добавлены отдельным этапом в соответствии с документом `46_DEFERRED_UNASSIGNED_WINDINGS_AND_ANALOGUE_MOTORS.md`.
