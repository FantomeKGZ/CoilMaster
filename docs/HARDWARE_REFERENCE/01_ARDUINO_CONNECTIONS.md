## Клавиатура 4×4

Физическая раскладка, используемая прошивкой:

```text
1  2  3  A
4  5  6  B
7  8  9  C
*  0  #  D
```

Матрица подключена напрямую восемью линиями D2…D9.

## LCD1602 I²C

Используется I²C LCD1602 с адресом:

```text
0x27
```

Для Arduino Uno стандартные I²C линии:

```text
A4 = SDA
A5 = SCL
```

Питание LCD подключать к соответствующим `5V` и `GND` модуля/платы.

## Зуммер

Сигнальный вывод зуммера перенесён с D11 на:

```text
A3
```

A3 используется как обычный цифровой выход. D11 больше не используется для зуммера и должен быть отсоединён от его сигнального входа.

Production firmware создаёт `BuzzerService` через `CM::Pins::Buzzer`, поэтому после прошивки актуальной версии сигнал формируется на A3. Зуммер используется для подтверждений и сигналов завершения катушки/программы, а также подтверждения аварийного `ALL_CLEAR`.

## SSR

Управляющий вывод SSR:

```text
D12
```

SSR управляется только Arduino. ESP32/Web не должны включать SSR напрямую.

Безопасное состояние после старта/ошибки — выключено, если state machine не разрешает движение.

## Hall SS49E

Сигнал Hall:

```text
A0
```

Текущие значения по умолчанию:

```text
threshold  = 590
hysteresis = 50
```

Они являются параметрами прошивки и могут быть изменены отдельно от физического pinout.

## Внешняя кнопка START

Подключена к:

```text
D10
```

В прошивке используется debounced input. Кнопка дублирует действие клавиши `A`: START или Resume, только когда state machine разрешает это действие.

## UART Arduino ↔ ESP32

Скорость:

```text
9600 baud
```

Фактическое направление:

```text
Arduino A1 TX  -> LLC -> ESP32 GPIO16 RX2
Arduino A2 RX  <- LLC <- ESP32 GPIO17 TX2
GND Arduino    -------- GND ESP32
```

`LLC` = преобразователь логических уровней. Для линии 5 V Arduino ↔ 3.3 V ESP32 преобразователь уровней обязателен/предпочтителен в соответствии с фактической сборкой.

Важно: TX одной платы всегда идёт на RX другой.

## Питание и земля

Все сигнальные модули должны иметь общую землю с соответствующей управляющей платой. Для UART Arduino ↔ ESP32 общая `GND` обязательна.

Не использовать эту таблицу как разрешение подавать 5 V непосредственно на GPIO ESP32. ESP32 — 3.3 V logic.
