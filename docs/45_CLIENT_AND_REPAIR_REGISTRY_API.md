# Реестр клиентов и ремонтов

## Назначение

Добавлена первая рабочая версия реестра мастерской. Клиенты и ремонты хранятся отдельно, а ремонт связывается с клиентом через `client_id`.

## Хранение

- `/data/workshop/clients.ndjson`
- `/data/workshop/repairs.ndjson`

## Клиенты

### Создание

`POST /api/clients`

Обязательные поля:

- `name`
- `phone`

Необязательное поле:

- `comment`

Телефон обязателен. Для поиска дополнительно сохраняется нормализованный номер, содержащий только цифры.

### Список и поиск

`GET /api/clients`

Поиск по телефону:

`GET /api/clients?phone=5551234`

Поиск работает по нормализованному номеру, поэтому пробелы, скобки, дефисы и знак `+` не мешают совпадению.

## Ремонты

### Создание

`POST /api/repairs`

Обязательные поля:

- `client_id`
- `motor_name`
- `received_at`

Необязательные поля:

- `complaint`
- `comment`

Новый ремонт получает статус `OPEN`. Создать ремонт для несуществующего клиента нельзя.

### Список

Все ремонты:

`GET /api/repairs`

Ремонты выбранного клиента:

`GET /api/repairs?client_id=12`

## Связь с уже реализованными разделами

Полученный `repair_id` используется в:

- списании провода;
- списании дополнительных материалов;
- калькуляции себестоимости;
- сохранении цены клиенту;
- будущей привязке истории намотки.

## Ограничение текущего этапа

В первой версии поле `motor_name` сохраняется непосредственно в ремонте. Следующим этапом будет отдельный реестр технологических карточек двигателей и связь ремонта с `motor_id`.
