# Отмена ожидающего задания намотки

## Назначение

ESP32 теперь может безопасно прекратить повторную передачу задания, которое ещё ожидает подтверждения Arduino.

Публичный метод:

```cpp
bool UartEventReceiver::cancelPendingJob(const char* detail = "CANCELLED");
```

## Поведение

Отмена разрешена только когда:

- существует ожидающее задание;
- предыдущий результат доставки уже обработан;
- текст причины соответствует формату протокола.

После успешной отмены создаётся `JobDeliveryEvent`:

- `result = JobDeliveryResult::Cancelled`;
- `jobId` содержит идентификатор отменённого задания;
- `sendAttempts` сохраняет число уже выполненных отправок;
- `detail` содержит причину отмены.

Повторы передачи немедленно прекращаются, а состояние ожидающего задания очищается.

## Ограничение безопасности

Метод отменяет только дальнейшую доставку задания с ESP32. Он не является удалённой аварийной остановкой и не управляет SSR. Если Arduino уже приняла задание, фактическое управление станком остаётся на Arduino и физических органах управления.

## Защита результата

До извлечения события через `takeJobDelivery()` новое задание поставить нельзя. Это предотвращает потерю результата `Cancelled`.
