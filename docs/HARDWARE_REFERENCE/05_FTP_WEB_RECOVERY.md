# FTP /web recovery — ESP32

Дата: **2026-08-19**  
Source of truth: `cmp-protocol-v1`

## Назначение

Встроенный FTP-сервер ESP32 предназначен только для обслуживания каталога `/web` на microSD. Он не предоставляет доступ к `/data` и производственным данным.

## Когда включается аварийный режим

Аварийный FTP запускается автоматически только если после монтирования microSD отсутствует хотя бы одна рабочая точка входа:

```text
/web/desktop/index.html
/web/mobile/index.html
```

Простого существования каталога `/web` недостаточно: FTP сам может создать этот каталог для восстановления.

После появления обеих точек входа аварийный режим автоматически останавливается с `last_result=automatic_recovery_complete`. Оператор при необходимости может отдельно запустить FTP вручную.

## Подключение

Порт управления: `21`. Пассивный порт: `50009`.

Подключаться можно:

- через AP CoilMaster, обычно `192.168.4.1`;
- через STA-IP ESP32 в той же локальной подсети, если ESP32 подключена к роутеру.

Клиенты вне локальной AP/STA-подсети отвергаются. Для PASV сервер сообщает IP того интерфейса, через который пришло управляющее соединение.

```text
User: CoilMaster
Password: CoilMaster123
Root: /web
```

FTP не шифрует трафик, поэтому использовать его следует только в доверенной локальной сети.
