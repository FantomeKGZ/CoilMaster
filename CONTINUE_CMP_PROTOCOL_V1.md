# Продолжение CoilMaster

Актуальная рабочая ветка:

```text
cmp-protocol-v1
```

Перед продолжением разработки прочитать весь каталог:

```text
docs/PROJECT_HANDOFF/
```

Начать с:

```text
docs/PROJECT_HANDOFF/00_READ_FIRST.md
```

Точная текущая задача находится в:

```text
docs/PROJECT_HANDOFF/06_ACTIVE_WORK_AND_NEXT_STEPS.md
```

Не использовать как текущую точку продолжения документы другой ветки, в которых указаны `main`, ранний CMP Core или каталоги `Shared/Protocol`.
