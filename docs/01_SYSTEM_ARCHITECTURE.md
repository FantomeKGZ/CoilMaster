# CoilMaster — системная архитектура

## Общая схема

```text
Датчик Холла / клавиатура / START / LCD1602
                    |
               Arduino Uno
                    |
          CMP Protocol через UART
                    |
          8-канальный LLC 5V↔3.3V
                    |
                  ESP32
        ┌───────────┼───────────┐
        │           │           │
      Wi‑Fi       microSD     DS3231
        │
   WEB‑портал
        │
 ПК / телефон / планшет
```

## Arduino Uno

Отвечает за:

- ввод количества катушек и витков;
- выполнение одного задания: рабочая или пусковая обмотка;
- подсчет витков по SS49E;
- управление SSR‑40DA;
- паузу, ручной режим и отмену сеанса;
- LCD1602;
- подтверждение завершения каждой катушки;
- автономную работу при отсутствии ESP32.

## ESP32

Отвечает за:

- локальный Wi‑Fi WEB‑сервер;
- прием состояния Arduino;
- подготовку и передачу заданий;
- хранение клиентов, двигателей, ремонтов и журналов;
- агрегацию одинаковых операций за период;
- привязку операций к ремонту и двигателю;
- RTC, microSD, резервные копии;
- калибровку и диагностику;
- размещение нескольких сайтов с Desktop/Mobile версиями.

## Аппаратные интерфейсы

### UART

```text
Arduino A1 TX → LLC → ESP32 GPIO16 RX2
Arduino A2 RX ← LLC ← ESP32 GPIO17 TX2
```

### I²C ESP32

- GPIO21 — SDA DS3231;
- GPIO22 — SCL DS3231.

### SPI microSD

- GPIO5 — CS;
- GPIO18 — SCK;
- GPIO19 — MISO;
- GPIO23 — MOSI.

## Надежность

- SSR при загрузке Arduino всегда выключен.
- Потеря Wi‑Fi не останавливает текущую намотку.
- ESP32 не помечает работу завершенной без отчета Arduino.
- Повторные команды определяются по Job ID и не создают дубликаты.
- Незавершенные операции получают статус `RESULT_UNKNOWN`, а не `COMPLETED`.
