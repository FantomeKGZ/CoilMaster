Автокалибровка датчика

ESP32 только переводит Arduino в режим ожидания. Для начала вращения необходимо самостоятельно нажать физическую кнопку START на станке. Автоматического запуска и прямого управления SSR нет.

Во время калибровки повторная START или любая клавиша на Arduino прерывает процедуру. Рекомендации threshold / hysteresis / direction не применяются автоматически.

Правила безопасности

Изменение параметров разрешается Arduino только в безопасном состоянии. Ответ BUSY означает, что станок сейчас нельзя перенастраивать. Для каждого фактического запуска по-прежнему требуется физическая кнопка START.
