# CoilMaster — сборка и первичная проверка Arduino Uno

## Назначение

Документ описывает воспроизводимую сборку объединённой прошивки Arduino Uno и безопасную проверку без подключения нагрузки 220 В.

## Автоматическая сборка

В корне репозитория находится `platformio.ini`. Среда `uno` собирает:

- `Core/*.cpp`;
- `Arduino/*.cpp`;
- `Arduino/CoilMaster_Arduino.ino`.

Используемые библиотеки устанавливаются PlatformIO автоматически:

- Keypad;
- LiquidCrystal_I2C.

Команда локальной сборки:

```bash
pio run -e uno
```

GitHub Actions выполняет ту же сборку после изменений Arduino/Core.

## Безопасность первого запуска

Первую проверку проводить без подключения силовой цепи 220 В к SSR-40DA. Управляющий вход SSR допускается оставить подключённым к D12, но нагрузочная сторона должна быть обесточена.

Перед подачей питания проверить:

- общий GND всех низковольтных модулей;
- LCD1602: SDA=A4, SCL=A5;
- Hall SS49E: сигнал=A0;
- внешняя START-кнопка: D10–GND;
- зуммер: D11–GND;
- SSR: управляющий плюс=D12, минус=GND;
- клавиатура: D2…D9;
- UART с ESP32 пока может быть физически отключён.

## Проверка интерфейса

1. После запуска SSR должен оставаться выключенным.
2. LCD должен показать ввод количества катушек.
3. Ввести, например, две катушки: `2#`, затем `5#`, `3#`.
4. Экран должен перейти в состояние готовности первой катушки.
5. Клавиша `*` должна удалять последнюю цифру только в режиме ввода.
6. Клавиша `B` должна очистить текущий сеанс и вернуть главное меню без перезагрузки платы.
7. Клавиша `C` должна включать и выключать ручной режим; силовая нагрузка при стендовом тесте остаётся отключённой.
8. Клавиша `D` должна поставить активную намотку на паузу.
9. Клавиша `A` и внешняя кнопка D10 должны выполнять одинаковое действие START/продолжить.

## Проверка счёта Hall

Для задания `5` витков провести магнит мимо SS49E пять раз. Один проход должен давать один виток. Если возникают пропуски или двойной счёт, откалибровать порог и гистерезис.

После пятого витка:

- команда SSR должна выключиться немедленно;
- зуммер должен подать три неблокирующих сигнала;
- система должна остаться в ожидании;
- следующая катушка не должна запускаться автоматически;
- продолжение допускается только клавишей `A` или внешней кнопкой START.

После завершения последней катушки система должна показать завершение задания и ожидать `B` для возврата в меню.

## Режим симуляции

Для проверки без магнита изменить в `Arduino/Config/CM_Features.h`:

```cpp
#define CM_FEATURE_SIMULATION 1
```

В режиме симуляции программные витки генерируются автоматически, а физический выход SSR должен быть заблокирован независимо от состояния машины.

Перед эксплуатацией станка вернуть:

```cpp
#define CM_FEATURE_SIMULATION 0
```

## Критерии допуска к силовому тесту

Подключать силовую цепь разрешается только после успешной проверки:

- сборка проходит без ошибок;
- D12 находится в LOW после запуска, паузы, завершения и сброса;
- одна магнитная метка считается один раз;
- следующая катушка не запускается сама;
- `B` гарантированно выключает команду SSR и возвращает меню;
- режим симуляции отключён.
