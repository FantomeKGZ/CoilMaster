# Разделение каталога провода по материалу

## Цель

Медь и алюминий с одинаковым диаметром больше не считаются одним складским остатком.
Калькулятор использует только катушки целевого материала.

## Новое поведение

При расчёте:

- `target_material=CU` — каталог строится только по катушкам с `wire_type="CU"`;
- `target_material=AL` — каталог строится только по катушкам с `wire_type="AL"`.

Старые записи без `wire_type` исключаются из расчёта и не считаются медными по умолчанию.

## Диаметры с нулевым остатком

Диаметр остаётся известным каталогу, даже если соответствующая катушка имеет нулевой остаток или неактивный статус.
Такой диаметр может участвовать в рекомендации со статусом `PURCHASE_REQUIRED`.

Остаток `available_g` суммируется только по активным катушкам выбранного материала.

## Ответ API

`GET /api/calculator/conductor` теперь дополнительно возвращает:

```json
{
  "catalogue_material": "CU",
  "legacy_unknown_material_excluded": true
}
```

Если для целевого материала нет ни одного известного диаметра:

```json
{
  "error": "wire_catalogue_empty_for_material",
  "target_material": "CU"
}
```

HTTP-статус: `404 Not Found`.

## Совместимость

Старый внутренний метод загрузки общего списка диаметров сохранён для существующих экранов.
Калькулятор использует новый материал-зависимый метод.
