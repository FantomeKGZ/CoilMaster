# CoilMaster — распиновка Arduino Uno

Статус: подтверждено пользователем.

## Карта выводов

| Пин | Назначение |
|---|---|
| D0 | Зарезервирован для USB Serial |
| D1 | Зарезервирован для USB Serial |
| D2–D9 | Матричная клавиатура 4×4, контакты 1–8 строго по порядку |
| D10 | Внешняя кнопка START, второй контакт на GND, режим INPUT_PULLUP |
| D11 | Зуммер: длинная ножка (+), короткая ножка на GND |
| D12 | Управляющий вход SSR-40DA: клемма 3 (+), клемма 4 на GND |
| D13 | Свободен, с учетом встроенного LED |
| A0 | Сигнал датчика Холла SS49E |
| A1 | SoftwareSerial TX к ESP32 через LLC |
| A2 | SoftwareSerial RX от ESP32 через LLC |
| A3 | Свободен |
| A4 | I²C SDA дисплея LCD1602 |
| A5 | I²C SCL дисплея LCD1602 |

## LCD1602 I²C

- VCC → +5 В
- GND → GND
- SDA → A4
- SCL → A5

## SS49E

При ориентации лицевой стороной со скошенными углами к пользователю:

- ножка 1, левая → +5 В;
- ножка 2, средняя → GND;
- ножка 3, правая → A0.

## Кнопка START

- контакт 1 → D10;
- контакт 2 → GND;
- программно использовать `INPUT_PULLUP`;
- нажатие соответствует уровню `LOW`.

## Ограничения

Arduino Uno имеет 2 КБ SRAM. В прошивке не использовать динамическое выделение памяти и избегать класса `String`. D0/D1 сохраняются для прошивки и отладки.
