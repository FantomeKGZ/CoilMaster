# Фильтрация бухт по материалу

## API

Список активных бухт:

`GET /api/warehouse/spools`

Поддерживается параметр:

`material=ALL|CU|AL|UNKNOWN`

Примеры:

- `/api/warehouse/spools?material=CU` — только медные бухты;
- `/api/warehouse/spools?material=AL` — только алюминиевые бухты;
- `/api/warehouse/spools?material=UNKNOWN` — старые записи без подтверждённого материала;
- `/api/warehouse/spools?material=ALL` — все активные бухты.

Дополнительно можно передать `diameter_hundredths_mm`.

Каждая запись ответа получает поле:

```json
{"material_class":"CU"}
```

Для старых записей:

```json
{"material_class":"UNKNOWN","legacy_unknown_material":true}
```

Неизвестный материал не преобразуется в медь автоматически.

## Интерфейс

Мобильная и настольная страницы склада получили:

- обязательный выбор материала при добавлении новой бухты;
- отдельные фильтры `Все`, `Медь`, `Алюминий`, `Без материала`;
- список отдельных активных бухт;
- предупреждение, что старые записи без материала не участвуют в рекомендациях калькулятора.

## Совместимость

Сводка склада по диаметрам пока остаётся общей. Разделение сводных остатков и расхода по материалам будет выполнено отдельным этапом, чтобы не смешивать изменение формата существующего API с добавлением фильтра списка бухт.
