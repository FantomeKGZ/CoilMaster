# CoilMaster — мобильный и ПК-интерфейс

## Цель

CoilMaster использует один API и одну базу данных, но предоставляет две самостоятельные компоновки интерфейса:

```text
/web/index.html          — выбор версии
/web/mobile/index.html   — мобильная версия
/web/desktop/index.html  — версия для ПК
```

Выбор версии сохраняется локально в браузере через `localStorage`. В каждом интерфейсе должна оставаться явная возможность переключиться на другую версию.

## Мобильная версия

Мобильный интерфейс предназначен для работы возле станка одной рукой.

Основные правила:

- нижняя навигация;
- крупные кнопки и поля ввода;
- карточки вместо широких таблиц;
- важные действия доступны за 2–3 нажатия;
- состояние системы находится в `Настройки → Состояние системы`;
- на остальных страницах отображается только общий индикатор `Система: норма/внимание/ошибка`;
- физический запуск SSR из браузера запрещён.

Основная навигация:

```text
Главная | Намотка | Поиск | Склад | Ещё
```

## Версия для ПК

ПК-интерфейс предназначен для расширенного мониторинга и работы с базами.

Основные правила:

- постоянное боковое меню;
- таблицы, фильтры и поиск;
- одновременное отображение намотки, статистики и состояния оборудования;
- отдельная карточка `Здоровье системы` на рабочем экране;
- быстрый доступ к ремонтам, клиентам, двигателям, складу и истории.

## Общий API

Обе версии используют одни и те же точки доступа:

```text
GET  /api/status
POST /api/jobs
GET  /api/warehouse/summary
GET  /api/system/health
```

Новые функции добавляются сначала в API, после чего отображаются в обеих версиях без дублирования бизнес-логики.

## Безопасность интерфейса

- WEB не включает SSR напрямую;
- запуск намотки выполняется клавишей `A` или внешней кнопкой START;
- удаление, восстановление резервной копии и складская корректировка требуют подтверждения;
- состояние форм не должно теряться при случайном обновлении страницы;
- интерфейс работает в локальной сети без доступа к интернету.
