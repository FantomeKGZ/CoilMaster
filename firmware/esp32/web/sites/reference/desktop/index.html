Справочник обмотчика

Версия для ПК

Исходный справочник

Подготавливается перенос материалов из motor-winding-reference без потери таблиц, схем, изображений и описаний. Верхний логотип исходного сайта в новой версии использоваться не будет.

Таблицы и данные двигателей

Табличные данные будут сохранены с горизонтальной прокруткой для широких таблиц.

Схемы и изображения

Общие изображения desktop/mobile будут вынесены в единый shared-каталог, уникальные останутся в своей версии.

Описания

Текстовые пояснения и внутренние переходы сохраняются при импорте.

Версия интерфейса

Переключение ПК ↔ мобильная использует тот же ключ cm-ui-version, что основной CoilMaster.
