# Ограниченные повторы доставки задания намотки

ESP32 больше не повторяет передачу задания на Arduino бесконечно.

## Политика доставки

- интервал между попытками: `2000 ms`;
- максимальное количество отправок одного задания: `5`;
- после пятой отправки ESP32 ждёт полный интервал подтверждения;
- если подтверждение не пришло, доставка завершается результатом `TimedOut`;
- после тайм-аута очередь освобождается, поэтому оператор или управляющий модуль может принять решение о повторной постановке задания.

## Результат доставки

`JobDeliveryResult` теперь содержит:

- `Accepted` — Arduino приняла задание;
- `Rejected` — Arduino явно отклонила задание;
- `TimedOut` — после пяти отправок подтверждение не получено.

`JobDeliveryEvent` дополнительно содержит `sendAttempts`, чтобы вызывающий код видел фактическое количество отправок.

## Защита подтверждений

ESP32 принимает только точные статусы:

- `ACCEPTED`;
- `REJECTED`.

Неизвестный статус больше не трактуется как отказ и не завершает ожидающую доставку.

## Безопасность

Тайм-аут доставки не запускает SSR и не считается подтверждением физического запуска. Для начала каждой катушки по-прежнему требуется локальное физическое подтверждение на Arduino.
