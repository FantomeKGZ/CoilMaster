# CoilMaster — интерфейс управления Arduino Uno

Статус: утвержденная базовая логика пользовательского интерфейса.

## 1. Органы управления

| Клавиша / кнопка | Назначение |
|---|---|
| `A` | Старт новой катушки или продолжение после паузы |
| Внешняя кнопка D10 | Полностью дублирует клавишу `A` |
| `B` | Отмена текущего сеанса, очистка временных данных и возврат в главное меню без перезагрузки Arduino |
| `C` | Ручной ход нагрузки через SSR без подсчета витков; повторное нажатие выключает ручной режим |
| `D` | Пауза автоматической намотки |
| `*` | Удаление последней введенной цифры |
| `#` | Подтверждение текущего ввода |
| `0...9` | Ввод количества катушек и числа витков |

`B` не является аварийной аппаратной остановкой и не перезагружает плату.

## 2. Основной сценарий ввода

1. Arduino показывает запрос количества катушек.
2. Пользователь вводит число и подтверждает `#`.
3. Arduino поочередно запрашивает число витков для каждой катушки.
4. После ввода последней уставки формируется текущее задание.
5. Задание передается ESP32 для сохранения.
6. После подтверждения или при автономной работе Arduino переходит в состояние готовности.
7. Запуск выполняется клавишей `A` или внешней кнопкой D10.

## 3. Экраны LCD1602

Формулировки должны оставаться максимально близкими к старому интерфейсу.

### Ввод количества катушек

```text
КОЛ-ВО КАТУШЕК?
ВВОД И НАЖМИ #
```

### Ввод числа витков

```text
ВИТКИ КАТ. 2
ВВОД: 35
```

### Готовность

```text
ГОТОВО КАТ. 2/4
НАЖМИ A СТАРТ
```

### Намотка

```text
НАМОТКА КАТ. 2
ВИТКИ 18/35
```

### Пауза

```text
ПАУЗА КАТ. 2
ВИТКИ 18/35
```

### Ручной режим

```text
РУЧНОЙ РЕЖИМ
НАЖМИ C СТОП
```

### Завершение программы

```text
НАМОТКА ЗАВЕРШ.
НАЖМИ B В МЕНЮ
```

## 4. Поведение после завершения катушки

- SSR немедленно переводится в безопасное состояние `LOW`;
- намотка останавливается;
- зуммер подает три сигнала;
- Arduino отправляет ESP32 подтверждение завершения текущей катушки;
- следующая катушка не запускается автоматически;
- оператор физически подтверждает продолжение клавишей `A` или кнопкой D10.

## 5. Пауза

При нажатии `D` во время автоматической намотки:

- SSR выключается;
- текущее число витков сохраняется;
- состояние переходит в `PAUSED`;
- `A` или D10 продолжает намотку с текущего значения.

## 6. Ручной режим

Ручной режим разрешается только когда автоматическая намотка не выполняется.

- первое нажатие `C` включает SSR;
- датчик Холла и счетчик витков не учитываются;
- повторное нажатие `C` выключает SSR;
- переход в автоматический режим возможен только после выхода из ручного режима.

## 7. Требования к реализации на Arduino Uno

- не использовать `String`, `new`, `malloc`;
- использовать фиксированные буферы;
- не использовать блокирующие `delay()` в основной логике;
- не ждать отпускания кнопки через пустой цикл;
- реализовать антидребезг неблокирующим способом;
- не выходить за пределы массива катушек;
- SSR должен быть `LOW` при старте, сбросе сеанса, ошибке и потере допустимого состояния;
- интерфейс, счетчик Холла, связь CMP и управление SSR должны быть разделены на независимые модули.

## 8. Источник задания

Задание может поступить:

- с локальной клавиатуры Arduino;
- из Web-интерфейса ESP32.

В обоих случаях данные отображаются на LCD1602 и требуют локального физического запуска клавишей `A` или кнопкой D10.
