# Поиск похожих двигателей

Добавлен предварительный поиск похожих карточек перед созданием двигателя.

## API

`GET /api/motors/similar`

Параметры:

- `coil_program` — обязательный;
- `name` — необязательный;
- `model` — необязательный;
- `manufacturer` — необязательный.

Пример:

`/api/motors/similar?coil_program=140%2F100%2F80%2F40&name=Leo&model=XKm%2080-1`

## Уровни совпадения

- `SAME_PROGRAM_ONLY` — совпала только программа витков;
- `POSSIBLE_ANALOGUE` — программа и одно поле идентификации;
- `LIKELY_SAME_MOTOR` — программа и не менее двух полей идентификации.

Ответ содержит:

- `same_program_count`;
- `identity_match_count`;
- список похожих карточек;
- `creation_blocked: false`.

Поиск является только предупреждением. Он никогда не запрещает создать отдельную карточку двигателя, поскольку одинаковые витки могут применяться у разных производителей и с разными проводами.

Поля провода и варианты обмоток будут добавлены следующим этапом. После этого полная спецификация обмотки будет сравниваться отдельно от идентификации двигателя.
