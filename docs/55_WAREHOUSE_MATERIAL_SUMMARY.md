# Сводка склада по материалам

## API

Добавлен отдельный endpoint:

`GET /api/warehouse/material-summary?month=YYYY-MM`

Он не изменяет формат старого `/api/warehouse/summary` и поэтому сохраняет обратную совместимость.

Ответ всегда содержит три раздела:

- `CU` — медные бухты;
- `AL` — алюминиевые бухты;
- `UNKNOWN` — старые записи без подтверждённого материала.

Пример структуры:

```json
{
  "month":"2026-08",
  "legacy_unknown_material_separate":true,
  "materials":[
    {
      "material":"CU",
      "remaining_g":12400,
      "active_spools":2,
      "consumed_month_g":350,
      "consumed_all_time_g":920,
      "diameter_count":2,
      "diameters":[
        {
          "diameter_hundredths_mm":80,
          "remaining_g":7400,
          "active_spools":1,
          "consumed_month_g":200,
          "consumed_all_time_g":500
        }
      ]
    }
  ]
}
```

## Определение материала расхода

Для подтверждённых списаний система сначала использует сохранённое в движении поле `wire_type`, когда оно присутствует.

Для старых движений без этого поля материал определяется по `spool_id` из текущей карточки бухты. Если материал определить нельзя, расход относится к `UNKNOWN`.

## Правила

- `UNKNOWN` никогда не считается медью автоматически.
- Остатки одинакового диаметра объединяются только внутри одного материала.
- Расход за месяц считается только для `CONFIRMED` операций `WRITE_OFF` с временной меткой, начинающейся с выбранного `YYYY-MM`.
- Общий расход включает все подтверждённые списания.
- Старый API общей сводки пока оставлен без изменений для существующих экранов и клиентов.
