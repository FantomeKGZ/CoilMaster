# CoilMaster — журнал намоток ESP32 на microSD

## Назначение

ESP32 сохраняет события, полученные от Arduino Uno, до отправки подтверждения по UART. Это гарантирует, что ответ `SAVED` означает успешную запись на microSD, а не только получение пакета.

## Подключение microSD

Используется аппаратная SPI-шина ESP32:

```text
CS   -> GPIO5
SCK  -> GPIO18
MISO -> GPIO19
MOSI -> GPIO23
```

## Файл журнала

События добавляются в файл:

```text
/data/winding-runs/events.ndjson
```

Каждая строка является отдельной JSON-записью. Пример:

```json
{"schema_version":1,"run_id":2,"event":"RUN_COMPLETED","session_id":1,"completed_runs":2,"uptime_ms":125430}
```

В журнал записываются:

- `RUN_STARTED`;
- `RUN_COMPLETED`;
- `session_id`;
- `run_id`;
- число завершённых повторов;
- время работы ESP32 в миллисекундах.

После подключения RTC поле `uptime_ms` будет дополнено календарной датой и временем DS3231.

## Подтверждения Arduino

После успешной записи:

```text
CMP1|ACK|<run_id>|RECORDED
CMP1|ACK|<run_id>|SAVED
```

`RECORDED` используется для `RUN_STARTED`, `SAVED` — для `RUN_COMPLETED`.

Если та же пара `run_id + event` уже находится в журнале:

```text
CMP1|ACK|<run_id>|DUPLICATE
```

Повторный пакет не создаёт вторую запись. Это позволяет Arduino безопасно повторять передачу после потери ответа.

При ошибке:

```text
CMP1|NACK|<run_id>|STORAGE_UNAVAILABLE
CMP1|NACK|<run_id>|WRITE_FAILED
```

Arduino не должна считать событие синхронизированным после `NACK`.

## Поведение без microSD

Отсутствие карты не блокирует локальную работу намоточного станка. Arduino продолжает управлять намоткой автономно, но ESP32 отвечает `STORAGE_UNAVAILABLE`. В дальнейшем Arduino должна хранить несколько неподтверждённых итогов и повторить отправку после восстановления microSD или связи.

## Защита данных

Текущая версия использует добавление неизменяемых NDJSON-записей. Последующие этапы:

1. добавить дату и время RTC DS3231;
2. создать индекс `run_id` для быстрого поиска без полного чтения журнала;
3. добавить очередь неподтверждённых событий на Arduino;
4. выполнять ротацию журнала по дате или размеру;
5. добавить резервное копирование и проверку целостности.
