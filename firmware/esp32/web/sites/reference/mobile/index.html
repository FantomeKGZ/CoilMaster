Справочник обмотчика

Мобильная версия

Исходный справочник

Подготавливается перенос материалов из motor-winding-reference без потери таблиц, схем, изображений и описаний. Верхний логотип исходного сайта в новой версии использоваться не будет.

Таблицы и данные двигателей

Широкие таблицы сохраняются и получают безопасную горизонтальную прокрутку на телефоне.

Схемы и изображения

Общие изображения desktop/mobile будут использовать один shared-ресурс вместо двух копий.

Описания

Текст, схемы и переходы останутся доступны в мобильной версии.

Версия интерфейса

Переключатель ПК ↔ мобильная использует общий ключ cm-ui-version CoilMaster.
