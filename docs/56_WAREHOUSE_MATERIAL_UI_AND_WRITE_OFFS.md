# Материальная сводка склада и списания

## Интерфейс склада

Мобильная и настольная страницы склада теперь используют:

`GET /api/warehouse/material-summary?month=YYYY-MM`

Общие показатели вычисляются как сумма трёх независимых разделов:

- `CU` — медь;
- `AL` — алюминий;
- `UNKNOWN` — старые записи без подтверждённого материала.

Для каждого материала интерфейс показывает:

- остаток;
- число активных бухт;
- расход за месяц;
- расход за всё время;
- разбивку по диаметрам.

`UNKNOWN` визуально помечается как старые записи и не смешивается с медью.

## Журнал списаний

Новые подтверждённые операции `WRITE_OFF` теперь сохраняют поле:

```json
{"wire_type":"CU"}
```

или:

```json
{"wire_type":"AL"}
```

Материал берётся непосредственно из карточки списываемой бухты в момент проверки ожидаемого веса и изменения остатка.

Это делает историю устойчивой к последующим изменениям карточки бухты и избавляет новую сводку от необходимости восстанавливать материал через `spool_id` для новых операций.

## Совместимость

Старые подтверждённые движения без `wire_type` продолжают поддерживаться. Для них материал определяется через текущую карточку бухты. Если определить материал нельзя, запись относится к `UNKNOWN`.

Записи `PENDING` не участвуют в статистике и могут не содержать материал. Поле `wire_type` обязательно записывается в успешной записи `CONFIRMED`, когда оно известно у бухты.
