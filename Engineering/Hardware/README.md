## Текущая архитектура

```text
LM2596, линия 5 В
        |
        +-- Arduino Uno — основной контроллер станка
        |     +-- LCD1602 I2C
        |     +-- SS49E
        |     +-- Keypad 4x4
        |     +-- START
        |     +-- Buzzer
        |     +-- SSR control
        |
        +-- ESP32 — коммуникационный контроллер
              +-- Wi-Fi / Web
              +-- OTA
              +-- DS3231, I2C GPIO21/GPIO22
              +-- microSD, SPI GPIO5/GPIO18/GPIO19/GPIO23
              +-- UART2 GPIO16/GPIO17

Arduino Uno <-- 8-channel LLC --> ESP32
```

## Распределение ответственности

### Arduino Uno

- выполняет основную логику намотки;
- считает витки по SS49E;
- управляет SSR;
- обрабатывает клавиатуру и кнопку START;
- выводит данные на LCD1602;
- подает звуковые сигналы.

### ESP32

- предоставляет Wi-Fi и веб-интерфейс;
- выполняет OTA-обновление;
- работает с RTC DS3231;
- работает с microSD;
- обменивается данными с Arduino Uno по CMP Protocol;
- не имеет локального дисплея.

## Подтверждено

- полная распиновка Arduino Uno;
- UART Uno ↔ ESP32;
- ESP32 UART2 GPIO16/GPIO17;
- ESP32 I2C GPIO21/GPIO22 для DS3231;
- ESP32 SPI microSD: CS GPIO5, SCK GPIO18, MISO GPIO19, MOSI GPIO23;
- LM2596 как источник линии 5 В;
- общий GND всех логических модулей;
- LCD1602 является единственным локальным дисплеем и подключен к Arduino Uno.

## Требует уточнения

- точная модель платы ESP32;
- точная модель платы расширения;
- входное напряжение и максимальный ток источника LM2596;
- наличие предохранителя и общего выключателя.
