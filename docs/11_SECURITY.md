# CoilMaster — безопасность и защита данных

## Безопасность станка

- SSR всегда переводится в `LOW` при запуске, сбросе, ошибке и потере допустимого состояния;
- Web-интерфейс не запускает двигатель напрямую;
- удаленное задание требует локального запуска клавишей A или кнопкой D10;
- команда B прекращает текущий сеанс и возвращает в главное меню без перезагрузки;
- неизвестная или поврежденная команда CMP отклоняется;
- при потере ESP32 Arduino продолжает автономную работу;
- при потере Arduino ESP32 не показывает станок как работающий без свежего подтверждения.

## Защита от повторных команд

Каждая изменяющая команда содержит идентификатор. Повторная доставка не должна повторно создавать задание, завершать катушку или добавлять вторую запись в журнал.

## Web-доступ

Первая версия работает в доверенной локальной сети, но архитектура предусматривает:

- пароль администратора;
- отдельную пользовательскую сессию;
- ограничение частоты запросов;
- защиту изменяющих запросов токеном сессии;
- журнал административных действий;
- запрет прямого доступа к путям microSD.

Сторонние сайты получают только разрешенные API и не имеют прямого доступа к UART, GPIO, SSR или базовым файлам.

## Защита данных

- уникальные ID для клиентов, двигателей, ремонтов и операций;
- архивирование вместо удаления связанных записей;
- версия схемы данных;
- временный файл и атомарная замена, где это возможно;
- проверка целостности;
- резервная копия перед миграцией;
- подтвержденная история не перезаписывается без явного действия пользователя.

## Резервное копирование

Бэкап включает базы, настройки, калибровку и версию схемы. Восстановление выполняется только после проверки совместимости и явного подтверждения.

## Отказоустойчивость

После перезапуска ESP32 анализирует незавершенные задания. Статус не переводится в `COMPLETED` без сообщения Arduino. При неопределенности используется `RESULT_UNKNOWN`.

После восстановления UART стороны обмениваются текущими состояниями и последними подтвержденными идентификаторами операций.

## Электрическая безопасность

Программные меры не заменяют аппаратную аварийную остановку, защиту сети 220 В, предохранители, правильное заземление и безопасный монтаж силовой части.
