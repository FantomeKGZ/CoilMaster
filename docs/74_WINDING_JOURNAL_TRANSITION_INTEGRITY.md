# Целостность переходов журнала намотки

Журнал ESP32 теперь проверяет последовательность событий, полученных от Arduino.

## Допустимая последовательность

Для одного `run_id` сначала должен быть сохранён:

```text
RUN_STARTED
```

Только после него допускается:

```text
RUN_COMPLETED
```

Оба события должны иметь одинаковый ненулевой `session_id`.

## Блокируемые случаи

`WindingJournal::save()` возвращает `JournalSaveResult::InvalidTransition`, если:

- `run_id` равен нулю;
- `session_id` равен нулю;
- тип события равен `None`;
- `RUN_COMPLETED` пришёл без сохранённого `RUN_STARTED`;
- `session_id` завершения не совпадает с сессией запуска;
- завершение сообщает нулевое количество выполненных запусков.

Повтор того же события для того же `run_id` по-прежнему возвращает `Duplicate` и не создаёт вторую запись.

## Назначение

Проверка не управляет SSR и не запускает станок. Она защищает журнал ESP32 от ложного завершения, потерянного события запуска и смешивания событий разных сессий Arduino.
