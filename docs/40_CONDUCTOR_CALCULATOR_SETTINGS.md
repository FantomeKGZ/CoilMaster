# Настройки калькулятора проводника

Добавлено отдельное хранилище настроек двустороннего пересчёта меди и алюминия.

## Файлы

- `firmware/esp32/src/CM_ConductorSettings.h`
- `firmware/esp32/src/CM_ConductorSettings.cpp`

## Путь на microSD

`/data/settings/conductor-calculator.ndjson`

## Сохраняемые параметры

- `aluminium_to_copper_permille` — коэффициент алюминий → медь;
- `copper_to_aluminium_permille` — коэффициент медь → алюминий;
- `allowed_deviation_permille` — допустимое отклонение;
- `max_target_strands` — максимальное число параллельных целевых жил.

## Диапазоны

- коэффициенты: `0,100–3,000`;
- допустимое отклонение: `0,1–50,0 %`;
- число целевых жил: `1–8`.

## Надёжность записи

Настройки сначала сохраняются во временный файл:

`/data/settings/conductor-calculator.tmp`

После успешной записи временный файл переименовывается в основной. Это уменьшает риск повреждения настроек при сбое питания во время сохранения.

Если файл ещё не создан или повреждён, калькулятор использует значения по умолчанию из `ConversionSettings`.

## Следующий шаг

Подключить `ConductorSettingsStore` к основной прошивке и добавить API:

- `GET /api/settings/conductor-calculator`;
- `POST /api/settings/conductor-calculator`.

После этого коэффициенты будут задаваться через раздел «Настройки», а запрос калькулятора перестанет требовать их ручной передачи.
