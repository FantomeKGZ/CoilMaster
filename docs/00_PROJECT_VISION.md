# CoilMaster — концепция проекта

## Назначение

CoilMaster — модульная система управления намоточным станком и учета работ по перемотке электродвигателей.

Система состоит из двух контроллеров:

- **Arduino Uno** — реальное управление станком, подсчет витков, SSR, клавиатура, внешняя кнопка START, LCD1602 и зуммер.
- **ESP32** — Wi‑Fi, локальный WEB‑портал, microSD, RTC DS3231, базы данных, журналирование, резервные копии и обмен с Arduino по CMP Protocol.

## Основные цели

1. Надежно выполнять намотку катушек с разным количеством витков.
2. Работать автономно даже при отсутствии ESP32.
3. Передавать задания между WEB‑интерфейсом и Arduino.
4. Подтверждать фактическое завершение каждой катушки и всего задания.
5. Хранить клиентов, двигатели, ремонты и историю намоток.
6. Поддерживать несколько WEB‑сайтов на microSD с отдельными Desktop и Mobile версиями.
7. Предоставлять сервисные режимы калибровки и диагностики.

## Принципы архитектуры

- Arduino является источником истины о физическом процессе намотки.
- ESP32 является источником истины о сохраненных данных, истории и WEB‑интерфейсе.
- WEB‑команда не включает SSR напрямую.
- Удаленное задание должно быть подтверждено Arduino и запускаться оператором возле станка.
- Критическая логика не зависит от Wi‑Fi и microSD.
- Данные имеют версии формата и резервные копии.
- В коде Arduino не используется динамическая память и класс `String`.
