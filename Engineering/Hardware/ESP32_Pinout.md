# CoilMaster — распиновка и подключение ESP32

Статус: частично подтверждено. В документ включены только подключения и правила, которые были явно согласованы в переписке и на реальной сборке.

## 1. ESP32 и плата расширения

ESP32 установлена на плату расширения с трехрядными гребенками:

- `S` — сигнальный вывод GPIO;
- `V` — линия питания модуля, 5 В или 3,3 В в зависимости от выбранной шины платы;
- `G` — общий GND.

Питание платы расширения подается от выхода LM2596 на вход `VIN` или `5V` и `GND` согласно маркировке конкретной платы.

Перед подключением необходимо проверить мультиметром, что выход LM2596 настроен на 5,0 В.

## 2. Подтвержденная карта GPIO

| GPIO ESP32 | Назначение | Вторая сторона |
|---|---|---|
| GPIO16 | UART2 RX | Принимает данные от Arduino Uno A1 (TX) через LLC |
| GPIO17 | UART2 TX | Передает данные на Arduino Uno A2 (RX) через LLC |
| GPIO21 | I²C SDA | DS3231, метка P21 на плате расширения |
| GPIO22 | I²C SCL | DS3231, метка P22 на плате расширения |

## 3. RTC DS3231

### Питание

- `VCC` → общая линия питания 5 В или 3,3 В, в зависимости от конкретной платы модуля;
- `GND` → общий GND.

### I²C

| DS3231 | ESP32 |
|---|---|
| SDA | GPIO21 / P21 |
| SCL | GPIO22 / P22 |

Программная инициализация:

```cpp
Wire.begin(21, 22);
```

## 4. microSD

Модуль microSD подключен к аппаратной шине SPI ESP32.

### Питание

- `VCC` → 5 В или 3,3 В строго в соответствии с маркировкой и схемой конкретного модуля;
- `GND` → общий GND.

### SPI

Используются линии:

- `CS`;
- `MOSI`;
- `MISO`;
- `SCK`.

Точные GPIO для SPI и вывод `CS` пока не подтверждены в доступной документации. До фиксации реальной распиновки эти значения нельзя жестко задавать в прошивке.

## 5. UART2 Arduino Uno ↔ ESP32

### ESP32

- GPIO16 — `RX2`;
- GPIO17 — `TX2`.

### Рекомендуемая инициализация

```cpp
constexpr int UART2_RX_PIN = 16;
constexpr int UART2_TX_PIN = 17;

Serial2.begin(57600, SERIAL_8N1, UART2_RX_PIN, UART2_TX_PIN);
```

Начальная скорость 57600 бод выбрана как более надежная для пары ESP32 HardwareSerial ↔ Arduino Uno SoftwareSerial. Скорость 115200 допускается только после отдельного продолжительного теста обмена без ошибок.

## 6. Преобразователь логических уровней LLC

LLC согласует логику ESP32 3,3 В и Arduino Uno 5 В.

### Питание LLC

| LLC | Подключение |
|---|---|
| LV | 3.3V ESP32 |
| HV | 5V |
| GND | Общий GND |

### Каналы UART

| Низковольтная сторона | Высоковольтная сторона | Направление |
|---|---|---|
| LV1 ← ESP32 GPIO17 (TX2) | HV1 → Arduino A2 (RX) | ESP32 → Arduino |
| LV2 → ESP32 GPIO16 (RX2) | HV2 ← Arduino A1 (TX) | Arduino → ESP32 |

Логически соединение выглядит так:

```text
ESP32 GPIO17 TX2 → LLC → Arduino A2 RX
ESP32 GPIO16 RX2 ← LLC ← Arduino A1 TX
```

## 7. Ограничения безопасности

- GPIO ESP32 работают только с логикой 3,3 В;
- нельзя подавать 5 В непосредственно на GPIO ESP32;
- земли ESP32, Arduino Uno, LLC, LM2596 и периферии должны быть общими;
- питание модулей через контакты `V` платы расширения выбирается только после проверки требуемого напряжения конкретного модуля;
- нельзя считать все контакты `V` автоматически 5-вольтовыми без проверки положения переключателей и схемы платы расширения.

## 8. Пока не подтверждено

- точная распиновка Nextion;
- точные GPIO microSD, включая `CS`;
- дополнительные кнопки или индикаторы ESP32;
- отдельные линии управления питанием;
- точная модель платы ESP32 и платы расширения.

Неподтвержденные выводы не должны использоваться в прошивке как окончательные.
