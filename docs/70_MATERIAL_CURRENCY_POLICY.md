# Валютная политика дополнительных материалов

Для новых позиций дополнительных материалов действует единая валюта:

```text
KGS_ONLY
```

## Создание материала

`POST /api/materials` принимает только `currency=KGS`.

Значение нормализуется:

- удаляются пробелы по краям;
- код переводится в верхний регистр.

Поэтому `kgs`, ` KGS ` и `KGS` сохраняются как `KGS`.

Любая другая валюта отклоняется до записи материала:

```json
{
  "error": "unsupported_currency",
  "supported_currency": "KGS",
  "currency_policy": "KGS_ONLY"
}
```

HTTP-статус: `400`.

## Успешный ответ

```json
{
  "created": true,
  "material_id": 4,
  "currency": "KGS",
  "currency_policy": "KGS_ONLY"
}
```

## Список материалов

`GET /api/materials` дополнительно сообщает:

```json
{
  "currency_policy": "KGS_ONLY",
  "supported_currency": "KGS"
}
```

## Причина ограничения

Калькуляция ремонта суммирует стоимость провода, дополнительных материалов и работы мастера. Смешивание разных валют без курса пересчёта создало бы недостоверную себестоимость и маржу. Поэтому новые материалы нельзя создавать в другой валюте.

Существующие исторические записи не переписываются автоматически.
