# Единственная активная намотка в сессии

## Назначение

Журнал ESP32 теперь запрещает одновременное существование двух незавершённых запусков в одной сессии Arduino.

Это поддерживает базовое правило станка: в каждый момент времени выполняется только одна намотка.

## Проверка RUN_STARTED

Перед сохранением нового `RUN_STARTED` журнал просматривает события этой `session_id`.

Если ранее был сохранён `RUN_STARTED`, но соответствующий `RUN_COMPLETED` ещё отсутствует, новый запуск отклоняется как `JournalSaveResult::InvalidTransition`.

Повтор того же уже сохранённого события по-прежнему определяется раньше и возвращает `JournalSaveResult::Duplicate`.

## Проверка RUN_COMPLETED

Завершение принимается только когда активный запуск этой сессии существует и его `run_id` совпадает с завершаемым запуском.

Таким образом отклоняются:

- завершение неактивного запуска;
- завершение старого запуска после начала другого;
- перекрывающиеся запуски в одной сессии;
- повреждённая история, содержащая несколько активных запусков.

## Поведение при повреждённом журнале

Если при чтении истории обнаружены два разных незавершённых `RUN_STARTED` в одной сессии, проверка считается неуспешной и новое событие не записывается. Это консервативное поведение предотвращает дальнейшее ухудшение журнала.

## Ограничение

Проверка выполняется отдельно для каждой `session_id`. Новая сессия Arduino после перезапуска не считается продолжением старой сессии автоматически.
