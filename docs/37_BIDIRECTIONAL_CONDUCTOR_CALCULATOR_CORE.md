# Ядро двустороннего пересчёта меди и алюминия

Добавлены:

- `firmware/esp32/src/CM_ConductorCalculator.h`
- `firmware/esp32/src/CM_ConductorCalculator.cpp`

## Поддерживаемые направления

- алюминий → медь;
- медь → алюминий;
- проверка той же марки материала без пересчёта.

## Исходные данные

Калькулятор принимает:

- материал исходной обмотки;
- диаметр одной жилы;
- число параллельных жил;
- целевой материал;
- отдельный коэффициент для выбранного направления;
- допустимое отклонение;
- максимальное число параллельных целевых жил;
- список диаметров, реально имеющихся на складе.

## Важное правило

В ядре нет жёстко зашитого «универсального» коэффициента пересчёта. Значения:

- `aluminiumToCopperPermille`;
- `copperToAluminiumPermille`

передаются из настроек и могут быть независимо изменены после проверки методики мастерской.

Значение `1000` означает отношение `1,000`, `850` — `0,850`, `1600` — `1,600`.

## Алгоритм

1. Рассчитывается суммарное геометрическое сечение исходного пучка.
2. Применяется коэффициент выбранного направления.
3. Перебираются складские диаметры.
4. Для каждого диаметра проверяются варианты от одной до заданного максимума параллельных жил.
5. Отбрасываются варианты за пределами допустимого отклонения.
6. Возвращается вариант с минимальным абсолютным отклонением.
7. Вместе с вариантом возвращается имеющийся на складе вес.

## Результат

`ConversionOption` содержит:

- целевой материал;
- диаметр;
- число параллельных жил;
- суммарное сечение;
- отклонение в промилле;
- доступный вес на складе.
