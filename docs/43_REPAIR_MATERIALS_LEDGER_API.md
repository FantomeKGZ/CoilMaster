# Учёт дополнительных материалов ремонта

## Назначение

Отдельный журнал материалов работает подобно кассе ремонта. Он учитывает не только провод, но и любые расходные позиции:

- подшипники;
- лак;
- пазовые клинья;
- изоляционную бумагу;
- шнур и ленту;
- крепёж;
- прочие материалы мастерской.

## Единицы измерения

Поддерживаются:

- `PIECE` — штуки;
- `GRAM` — граммы;
- `MILLILITRE` — миллилитры;
- `METRE` — метры;
- `SQUARE_METRE` — квадратные метры.

Количество хранится в тысячных долях единицы (`quantity_milli`). Это позволяет учитывать, например:

- `1500` = 1,5 литра или 1,5 метра;
- `250` = 0,25 штуки, если материал допускает дробное списание;
- `1000` = одна полная единица.

## Файлы microSD

- `/data/materials/materials.ndjson` — каталог и текущие остатки;
- `/data/materials/usage.ndjson` — подтверждённые списания по ремонтам.

## API каталога

### Список

`GET /api/materials`

### Добавление

`POST /api/materials`

Поля:

- `name`;
- `unit`;
- `stock_quantity_milli`;
- `price_per_unit_minor`;
- `currency` (по умолчанию `KGS`);
- `comment` — необязательно.

## API списания

`POST /api/materials/usage`

Поля:

- `repair_id`;
- `material_id`;
- `quantity_milli`;
- `timestamp`;
- `comment` — необязательно.

При подтверждении:

1. проверяется активность материала;
2. проверяется достаточность остатка;
3. количество вычитается из каталога;
4. цена копируется в операцию;
5. рассчитывается стоимость строки;
6. операция связывается с ремонтом через `repair_id`.

Изменение цены материала позднее не должно менять стоимость уже записанных операций.
