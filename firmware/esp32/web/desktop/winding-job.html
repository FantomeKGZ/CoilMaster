Отправить задание

Поле заблокировано для связанной намотки. Произвольная программа доступна только в сервисной отправке на главной странице.
Например, программа 38/38 и значение 6 означают один JOB: полный цикл 38/38 выполняется 6 раз. Каждый повтор начинается только отдельным физическим START.
Для связанной намотки выберите конкретную активную бухту Cu/Al. ESP32 сохранит её как immutable metadata задания.
Выбор бухты и RUN_COMPLETED не списывают провод автоматически. Фактический расход остаётся отдельным ручным подтверждением.
Автоматический запуск запрещён. Каждый повтор запускается только физической кнопкой START.
