# CoilMaster — интерфейс LCD1602

## Цель

Новый интерфейс сохраняет привычную логику старой прошивки, но реализуется через отдельный модуль представления и машину состояний.

## Основные экраны

### Ввод количества катушек

```text
КОЛ-ВО КАТУШЕК?
ВВОД И НАЖМИ #
```

### Ввод витков

```text
ВИТКИ КАТ. 2/4
ВВОД: 35
```

### Готовность

```text
ГОТОВО КАТ. 1/4
НАЖМИ A СТАРТ
```

### Намотка

```text
НАМОТКА КАТ. 1
ВИТКИ 18/35
```

### Пауза

```text
ПАУЗА КАТ. 1
ВИТКИ 18/35
```

### Ручной режим

```text
РУЧНОЙ РЕЖИМ
C — ОСТАНОВИТЬ
```

### Завершение

```text
НАМОТКА ГОТОВА
B — В ГЛ. МЕНЮ
```

### Задание с ESP32

```text
ЗАДАНИЕ ИЗ WEB
3 КАТ.  A-СТАРТ
```

Перед запуском пользователь может просмотреть программу по катушкам.

## Правила отображения

- строка всегда заполняется до 16 символов, чтобы не оставались старые символы;
- `lcd.clear()` не вызывается при каждом импульсе Hall;
- обновляются только изменившиеся поля;
- частота обновления прогресса ограничивается, но достижение цели обрабатывается немедленно;
- русские символы используют проверенную таблицу конкретного LCD1602.

## Обработка ввода

- цифры принимаются только в состояниях ввода;
- `*` удаляет одну цифру;
- `#` подтверждает число;
- `B` в любой момент безопасно выключает SSR и возвращает в начало;
- `A` и D10 имеют одинаковую бизнес-логику;
- `D` ставит активную автоматику на паузу;
- `C` доступна только в допустимом безопасном состоянии.

## Ошибки

Короткие сообщения должны быть понятными:

```text
ОШИБКА ДАННЫХ
B — В МЕНЮ
```

```text
НЕТ СВЯЗИ ESP
РАБОТА АВТОНОМНО
```

Отсутствие ESP32 не блокирует локальный ввод и намотку.
