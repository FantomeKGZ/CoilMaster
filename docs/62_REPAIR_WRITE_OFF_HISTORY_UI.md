# История списаний в карточке ремонта

Мобильная и настольная страницы списания провода теперь загружают историю выбранного ремонта через:

`GET /api/warehouse/write-offs?repair_id=<ID>`

## Отображаемые данные

Для ремонта показываются:

- общий подтверждённый расход провода;
- номер движения;
- номер бухты;
- материал;
- диаметр;
- списанная масса;
- вес до и после списания;
- дата и время;
- комментарий.

На мобильной странице история выводится отдельным блоком под формой. На настольной странице форма и история расположены рядом.

## Обновление

История загружается при открытии страницы. После успешного нового списания одновременно обновляются:

- актуальный остаток выбранной бухты;
- список доступных бухт;
- общий расход ремонта;
- список подтверждённых движений.

## Правила

- показываются только подтверждённые списания;
- новые записи отображаются первыми;
- старые движения без материала помечаются как `Материал не указан`;
- пользовательские комментарии экранируются перед выводом;
- отсутствие истории не считается ошибкой.
