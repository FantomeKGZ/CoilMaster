# Назначение материала старым бухтам

## Назначение

Старые записи склада могли быть сохранены без поля `wire_type`. Такие бухты отображаются как `UNKNOWN` и не участвуют в рекомендациях калькулятора.

Для их безопасной классификации добавлен отдельный API.

## API

`POST /api/warehouse/spools/material`

Параметры формы:

- `spool_id` — идентификатор активной бухты;
- `wire_type` — только `CU` или `AL`.

Пример успешного ответа:

```json
{"updated":true,"spool_id":12,"wire_type":"CU"}
```

## Ограничения

Материал можно назначить только активной бухте, у которой поле `wire_type` отсутствует.

API не позволяет:

- изменить уже установленный материал;
- присвоить значение, отличное от `CU` или `AL`;
- изменить несуществующую или неактивную бухту.

При конфликте возвращается:

```json
{"error":"legacy_spool_material_not_assigned"}
```

HTTP-статус: `409 Conflict`.

## Хранение

Файл `/data/warehouse/spools.ndjson` переписывается через временный файл `/data/warehouse/spools.tmp`.

Исходный файл заменяется только после полного успешного формирования новой версии. При ошибке временный файл удаляется, а исходные данные остаются без изменений.

После назначения материала бухта автоматически переносится из группы `UNKNOWN` в `CU` или `AL` при следующем запросе списка и сводки склада.
