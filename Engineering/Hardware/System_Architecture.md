# CoilMaster — архитектура аппаратной части

Статус: утверждено для текущей сборки.

## 1. Общая схема

```text
                         Wi-Fi / Web / OTA
                                |
                           +---------+
                           |  ESP32  |
                           +---------+
                            |   |   |
                DS3231 I2C -+   |   +-- microSD SPI
                                |
                         CMP Protocol UART2
                                |
                     8-канальный LLC 3.3/5 В
                                |
                         SoftwareSerial A1/A2
                                |
                         +---------------+
                         | Arduino Uno   |
                         +---------------+
                          |   |   |   |
                      LCD1602 |   |   +-- SSR-40DA
                              |   +------ Buzzer
                              +---------- Keypad / START / SS49E
```

## 2. Arduino Uno — основной контроллер

Arduino Uno отвечает за функции, связанные с непосредственным управлением станком:

- подсчет витков по аналоговому датчику Холла SS49E;
- управление SSR-40DA;
- обработка матричной клавиатуры 4x4;
- обработка внешней кнопки START;
- вывод текущих данных на LCD1602 I2C;
- звуковая индикация;
- обмен с ESP32 по CMP Protocol.

Станок должен сохранять базовую работоспособность даже при отключенной ESP32.

## 3. ESP32 — коммуникационный контроллер

ESP32 не управляет исполнительными устройствами станка напрямую и не имеет локального дисплея.

Ее задачи:

- Wi-Fi;
- веб-интерфейс;
- OTA-обновление;
- RTC DS3231;
- microSD;
- журналирование и хранение сервисных данных;
- удаленный обмен настройками и состоянием с Arduino Uno.

## 4. Каналы связи

### CMP Protocol

```text
Arduino Uno A1 TX → LLC → ESP32 GPIO16 RX2
Arduino Uno A2 RX ← LLC ← ESP32 GPIO17 TX2
```

На Arduino используется `SoftwareSerial`, на ESP32 — аппаратный `UART2`.

### I2C ESP32

```text
DS3231 SDA → GPIO21
DS3231 SCL → GPIO22
```

### SPI ESP32

```text
microSD CS   → GPIO5
microSD SCK  → GPIO18
microSD MISO → GPIO19
microSD MOSI → GPIO23
```

### I2C Arduino Uno

```text
LCD1602 SDA → A4
LCD1602 SCL → A5
```

## 5. Питание

LM2596 формирует линию 5 В для текущей сборки.

Перед подключением электроники выход необходимо установить мультиметром на 5,0 В.

Обязателен общий GND между:

- LM2596;
- Arduino Uno;
- ESP32;
- LLC;
- LCD1602;
- SS49E;
- DS3231;
- microSD;
- управляющей стороной SSR;
- кнопкой START;
- зуммером.

GPIO ESP32 работают только с логическими уровнями 3,3 В. UART между ESP32 и Arduino Uno проходит через LLC.

## 6. Принцип отказоустойчивости

- Arduino Uno выполняет критическую логику станка локально.
- Отказ Wi-Fi, веб-интерфейса, microSD или ESP32 не должен сам по себе приводить к неконтролируемому включению SSR.
- После запуска Arduino выход SSR должен быть переведен в безопасное состояние `LOW` до завершения инициализации.
- Команды от ESP32 должны проходить проверку состояния и допустимости на стороне Arduino Uno.

## 7. Отсутствующие модули

В текущей архитектуре не используются:

- Nextion;
- отдельный дисплей ESP32;
- прямое управление SSR или двигателем со стороны ESP32.
