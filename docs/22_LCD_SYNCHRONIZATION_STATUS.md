# Индикация синхронизации Arduino ↔ ESP32 на LCD1602

Arduino Uno показывает состояние сохранения фактических намоток в правой части первой строки LCD1602.

## Обозначения

```text
OK
```

Все завершённые намотки подтверждены ESP32. Неподтверждённых записей в EEPROM нет.

```text
P1 ... P9
```

Есть записи, ожидающие передачи или подтверждения. Цифра показывает количество завершённых проходов, сохранённых в EEPROM Arduino. Значения больше девяти отображаются как `P9`.

```text
E0 ... E9
```

Обнаружена ошибка синхронизации: очередь заполнена, запись не помещена в EEPROM/UART-очередь либо ESP32 отправила `NACK`. Цифра показывает количество защищённых EEPROM-записей, которые всё ещё ожидают подтверждения.

## Правила работы

- Индикатор занимает два последних символа первой строки и отображается на всех рабочих экранах.
- Ошибка связи не включает SSR и не меняет логику управления силовой частью.
- Arduino продолжает автономную работу.
- Завершённый проход удаляется из EEPROM только после `ACK` или `DUPLICATE` от ESP32.
- После успешного подтверждения последней ожидающей записи индикатор возвращается в `OK`.
- `RUN_STARTED` может находиться только в оперативной UART-очереди; `RUN_COMPLETED` дополнительно защищён EEPROM.

## Примеры

```text
NAMOTKA KAT.1 OK
VITKI:42/140
```

Связь и журнал работают нормально.

```text
GOTOVO: 2 RAZ P1
A=POVTOR B=MENU
```

Один завершённый проход ожидает сохранения ESP32.

```text
KATUSHKA GOTO E2
A=DAL'SHE
```

Есть ошибка синхронизации и две защищённые записи в EEPROM. Станок остаётся под локальным управлением Arduino.
