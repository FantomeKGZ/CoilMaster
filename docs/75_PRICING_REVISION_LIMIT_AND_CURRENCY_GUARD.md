# Ограничение редакций цены и контроль валюты

`POST /api/repairs/costing` дополнительно защищает append-only журнал цены ремонта.

## Каноническая валюта

Перед сравнением и сохранением значение `currency`:

1. очищается от пробелов по краям;
2. переводится в верхний регистр;
3. проверяется против поддерживаемой валюты `KGS`.

Например, `kgs` и ` KGS ` нормализуются в `KGS`.

Другая валюта отклоняется без записи:

```json
{
  "error": "unsupported_currency",
  "supported_currency": "KGS"
}
```

## Предел номера редакции

Счётчик редакций хранится как `uint16_t`, поэтому максимальный номер — `65535`.

Если достигнут предел и оператор пытается сохранить изменённые значения, сервер возвращает HTTP `409`:

```json
{
  "error": "pricing_revision_limit_reached",
  "current_revision": 65535,
  "revision_limit": 65535,
  "write_performed": false
}
```

Новая строка в `/data/repairs/pricing.ndjson` не создаётся.

Одинаковое повторное сохранение разрешено и при достигнутом пределе, поскольку оно не создаёт редакцию.

## Явный результат записи

Успешная новая редакция содержит:

```json
{
  "saved": true,
  "unchanged": false,
  "write_performed": true,
  "revision_advanced": true
}
```

Повторное сохранение без изменений содержит:

```json
{
  "saved": false,
  "unchanged": true,
  "write_performed": false,
  "revision_advanced": false
}
```

Это позволяет интерфейсу отличать реальную запись от безопасной операции без изменений.
